# 功能测试面板 (Test Dashboard)

## 概述

功能测试面板是一个集成化的测试界面，将所有功能测试整合到一个统一的页面中，方便开发人员快速测试和验证各个阶段的功能。

## 访问路径

- URL: `/test/dashboard`
- 导航菜单: 点击侧边栏的"功能测试面板"链接

## 功能特性

### 1. 统一的测试界面
- 所有测试集成在一个页面中
- 清晰的视觉分隔和组织
- 支持折叠/展开各个测试区域

### 2. 阶段二：属性计算测试
集成自 `AttributeCalculatorTest.razor`，包含以下测试：
- **测试1**: 加载职业配置
- **测试2**: 计算战士属性 (Level 1-10)
- **测试3**: 计算法师属性 (Level 1-10)
- **测试4**: 计算游侠属性 (Level 1-10)
- **测试5**: 性能测试 (100次计算)
- **测试6**: 属性上限测试 (Level 600)

### 3. 阶段三：触发集成测试
集成自 `AttributeCalculatorTest.razor`，包含以下测试：
- **P3测试1**: 模拟角色创建触发
- **P3测试2**: 模拟升级触发（战士 Lv1→Lv5）
- **P3测试3**: 模拟职业切换触发（战士→法师）
- **P3测试4**: 模拟战斗中升级触发
- **P3测试5**: 批量重算触发测试
- **P3测试6**: 事件系统验证
- **P3测试7**: 触发系统性能测试

### 4. 阶段四：持久化测试
集成自 `PersistenceTest.razor`，包含以下测试：
- **测试4.1**: 验证心跳保存机制
- **测试4.2**: 测试特定动作立即保存
- **测试4.3**: 测试属性保存和恢复

### 5. 一键运行所有测试
- 点击"🚀 一键运行所有测试"按钮
- 按顺序执行所有阶段的测试
- 自动展开所有测试区域
- 适合完整的功能回归测试

## 测试状态指示

每个测试区域都有状态徽章：
- **PENDING** (灰色): 测试尚未运行
- **RUNNING** (黄色): 测试正在运行中
- **SUCCESS** (绿色): 测试全部通过
- **FAILED** (红色): 测试失败

## 使用说明

### 单独运行某个阶段的测试
1. 确保对应的测试区域是展开的
2. 点击相应的测试按钮（如"运行阶段二测试"）
3. 等待测试完成
4. 查看输出结果

### 折叠/展开测试区域
- 点击区域标题栏即可折叠或展开
- 折叠后的区域用"▶"表示
- 展开的区域用"▼"表示

### 运行所有测试
1. 点击底部的"🚀 一键运行所有测试"按钮
2. 系统会自动按顺序运行所有测试
3. 所有区域会自动展开以显示进度

## 前置条件

### 阶段二和阶段三测试
- 需要后端 API 服务器运行（用于加载职业配置）
- API 地址配置在 `Configuration/ApiConfiguration.cs`

### 阶段四测试
- 测试4.1 和 4.3 可以离线运行
- 测试4.2 需要后端 API 服务器运行

## 输出格式

测试输出使用固定宽度字体显示，包括：
- ✓ 表示测试通过
- ✗ 表示测试失败
- ⚠ 表示警告信息
- 详细的测试结果和错误堆栈

## 添加新测试

要在测试面板中添加新的测试功能：

1. 在 `TestDashboard.razor` 中添加新的测试区域
2. 创建对应的测试方法
3. 添加按钮和输出显示区域
4. 更新状态管理逻辑

示例代码结构：
```razor
<div class="test-section">
    <div class="section-header" @onclick="() => ToggleSection(4)">
        <h4>
            <span class="toggle-icon">@(expandedSections.Contains(4) ? "▼" : "▶")</span>
            新测试名称
        </h4>
        <span class="status-badge @(newTestStatus)">@newTestStatus</span>
    </div>
    
    @if (expandedSections.Contains(4))
    {
        <div class="section-content">
            <button class="btn btn-primary" @onclick="RunNewTest">
                运行新测试
            </button>
            <pre class="test-output">@newTestOutput</pre>
        </div>
    }
</div>
```

## 设计理念

1. **统一管理**: 所有测试在一个页面中，避免在多个页面间切换
2. **清晰组织**: 按阶段分组，每个阶段有明确的测试目标
3. **状态可视化**: 实时显示测试状态和进度
4. **易于扩展**: 新测试可以轻松集成到现有框架中
5. **独立运行**: 每个测试都可以独立运行，互不干扰
