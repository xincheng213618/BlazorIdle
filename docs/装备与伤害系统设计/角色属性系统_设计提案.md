## 📋 概述

本文档描述角色属性系统的更新设计。核心变更：**角色属性 = 职业基础属性 + 装备属性**。

### 设计目标
1. 每个职业有独特的基础属性配置
2. 装备提供额外的属性加成
3. 为未来天赋系统预留扩展空间
4. 保持与现有伤害管线的兼容性

---

## 🎯 属性来源模型

### 最终属性公式

```
最终属性 = 职业基础属性 + 装备基础属性 + 装备词条属性 + (未来)天赋加成
```

### 详细分解

| 属性类型 | 职业提供 | 装备提供 | 说明 |
|---------|---------|---------|------|
| **基础攻击力 (AttackFinal)** | ✅ BaseAttack | ✅ 装备BaseAttack × 10件 | 加法叠加 |
| **基础生命值 (BaseHP)** | ✅ BaseHP | ✅ 装备BaseHP × 10件 | 加法叠加 |
| **攻击速度 (AttackRateAPS)** | ✅ | ❌ | 职业固有，通过急速词条增强 |
| **暴击率% (CritChancePercent)** | ✅ 初始值 | ✅ 词条加成 | 叠加后受上限裁剪 |
| **暴击伤害加成% (CritDamageBonusPercent)** | ✅ 初始值 | ✅ 词条加成 | 叠加后受上限裁剪 |
| **急速% (HastePercent)** | ✅ 初始值 | ✅ 词条加成 | 叠加后受上限裁剪 |
| **攻击% (AttackPercent)** | ❌ | ✅ 词条加成 | 仅装备提供 |
| **特攻% (SpecialAttackPercent)** | ❌ | ✅ 词条加成 | 仅装备提供 |
| **生命% (HPPercent)** | ❌ | ✅ 词条加成 | 仅装备提供 |
| **态势相关 (Fortify/Backwater)** | ❌ | ✅ 词条加成 | 仅装备提供 |
| **追击相关 (Chase/KenChase)** | ❌ | ✅ 词条加成 | 仅装备提供 |
| **减伤% (DamageReductionPercent)** | ❌ | ✅ 词条加成 | 仅装备提供 |

## 📊 职业差异化设计

### 基础属性对比

| 职业 | 基础攻击力 | 基础生命 | 攻速 | 初始暴击% | 初始急速% | 特点 |
|-----|----------|---------|------|---------|---------|------|
| 战士 | 100 | 500 | 0.40 | 5% | 0% | 高生命、稳定输出 |
| 法师 | 80 | 300 | 0.35 | 10% | 0% | 高爆发、初始特攻5% |
| 盗贼 | 70 | 350 | 0.50 | 15% | 10% | 高攻速、高暴击 |
| 游侠 | 85 | 400 | 0.45 | 8% | 5% | 平衡型 |

### 设计理念

1. **战士**：最高基础攻击和生命，适合新手，容错率高
2. **法师**：最低生命但初始带暴击和特攻加成，高风险高回报
3. **盗贼**：最高攻速和初始急速，追求高频率输出
4. **游侠**：平衡型，各方面都较为均衡

## 🔧 属性计算流程

### 1. 基础面板计算

```csharp
// 计算最终攻击力
int FinalAttack = Profession.BaseStats.BaseAttack 
                + Equipment.TotalBaseAttack;  // 10件装备基础攻击之和

// 计算最终生命值
int FinalBaseHP = Profession.BaseStats.BaseHP 
                + Equipment.TotalBaseHP;  // 10件装备基础生命之和

// 应用生命%加成
int FinalMaxHP = FinalBaseHP * (1 + HPPercent / 100);
```

### 2. 战斗属性汇总

```csharp
CombatStats CalculateFinalCombatStats(Profession profession, EquipmentLoadout equipment)
{
    var stats = new CombatStats();
    
    // 基础攻击力 = 职业基础 + 装备基础
    stats.AttackFinal = profession.BaseStats.BaseAttack + equipment.TotalBaseAttack;
    
    // 百分比属性 = 职业初始 + 装备词条汇总
    var equipStats = EquipmentCalculator.Calculate(equipment);
    
    stats.AttackPercent = profession.InitialCombatStats.AttackPercent + equipStats.AttackPercent;
    stats.SpecialAttackPercent = profession.InitialCombatStats.SpecialAttackPercent + equipStats.SpecialAttackPercent;
    stats.CritChancePercent = profession.InitialCombatStats.CritChancePercent + equipStats.CritChancePercent;
    stats.CritDamageBonusPercent = profession.InitialCombatStats.CritDamageBonusPercent + equipStats.CritDamageBonusPercent;
    stats.HastePercent = profession.InitialCombatStats.HastePercent + equipStats.HastePercent;
    stats.HPPercent = profession.InitialCombatStats.HPPercent + equipStats.HPPercent;
    stats.FortifyMaxPercent = equipStats.FortifyMaxPercent;
    stats.BackwaterMaxPercent = equipStats.BackwaterMaxPercent;
    stats.ChasePercent = equipStats.ChasePercent;
    stats.KenChasePercent = equipStats.KenChasePercent;
    stats.ChaseFlat = equipStats.ChaseFlat;
    stats.DamageReductionPercent = equipStats.DamageReductionPercent;
    
    // 应用上限裁剪
    return stats.Clamp(CombatCapsConfig);
}
```

## 📝 变更对比

### 旧系统
- 角色属性完全由装备提供
- 职业仅定义攻速、技能等固有属性

### 新系统
- 职业提供基础攻击力、基础生命值、初始战斗属性
- 装备提供额外的基础属性和词条加成
- 最终属性 = 职业 + 装备（+ 未来天赋）

### 对伤害管线的影响
- **无影响**：伤害管线只关心最终的 `CombatStats`，不关心属性来源
- 属性汇总在战斗开始前完成，管线逻辑无需修改
