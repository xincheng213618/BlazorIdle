## 📋 概述

本文档用于规划和追踪旧属性、Buff、伤害系统的清理工作。

**背景说明：**
- 新的装备与伤害系统（7层伤害管线）已完成实施（Phase 1-5）
- 新的Buff系统优化已完成实施
- 新的角色属性系统已完成实施（职业基础属性 + 装备属性）
- 现有代码中保留了大量旧系统逻辑用于向后兼容

**清理目标：**
- 移除废弃的属性和方法
- 清理向后兼容逻辑
- 简化代码结构
- 确保新系统完全接管

**重要提醒：**
- 清理前必须确保所有测试通过
- 清理过程中需要逐步验证
- 部分清理可能需要数据库迁移

**当前进度：**
- ✅ Phase 3: MultiBattleInstance 向后兼容逻辑已清理
- ✅ Phase 2: SkillResolver 旧逻辑已清理（移除旧伤害计算分支和 ApplyBuffEffects 方法）
- 🔄 Phase 8: 测试更新进行中
  - 已完成: SkillResolverPhase4Tests (11), Stage10IntegrationTests, EquipmentDamagePhase5Tests
  - 已更新: Phase8BuffEffectApplicationTests (部分), Phase7ImprovementsTests
  - 剩余: 14个测试需要更新
  - 当前测试通过率: 1167/1181 (98.8%)
