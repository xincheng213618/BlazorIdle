# 装备与伤害系统 - 实施进度追踪

本文档用于追踪装备与伤害系统的实施进度。

**目标：** 实现完整的装备系统（主手+9副槽）、词条系统（带元素激活机制）、以及新的7层伤害计算管线。

**原则：**

- ✅ 移除旧的角色属性概念（如 DamagePerAttack、SpecialDamage、CritMultiplier）

- [ ] 2.2 创建 DamageResult 类
  - [ ] 位置：BlazorIdle.Shared/Game/Combat/DamageResult.cs
  - [ ] FinalDamage（最终伤害）
  - [ ] IsCrit（是否暴击）
  - [ ] ElementMultiplier（元素乘区）
  - [ ] BaseDamage / AfterVariance / AfterMain / AfterCrit / AfterElement / AfterChase（各层中间值，用于调试）

- [ ] 2.3 创建 DamageCalculator 类
  - [ ] 位置：BlazorIdle.Shared/Game/Combat/DamageCalculator.cs
  - [ ] Calculate(DamageContext ctx) → DamageResult
  - [ ] 实现7层计算：
    1. 基础层：Base = AttackFinal × SkillCoef + SkillFlat
    2. 浮动层：AfterVariance = Base × Variance
    3. 主体层：AfterMain = AfterVariance × (1+Atk%) × (1+SpAtk%) × (1+Stance%)
    4. 暴击层：AfterCrit = AfterMain × (isCrit ? 1.2×(1+CritBonus%) : 1)
    5. 元素层：AfterElement = AfterCrit × ElementMult
    6. 追击层：AfterChase = AfterElement + Chase% + KenChase% + ChaseFlat
    7. 减伤层：Final = AfterChase × (1-ArmorCurve) × (1-DR%)

- [ ] 2.4 实现态势计算
  - [ ] CalcStancePercent(hpRatio, fortifyMax, backwaterMax)
  - [ ] 盛体：HP ≥ 75% → FortifyRaw = (HPRatio-0.75)/0.25
  - [ ] 背水：HP ≤ 50% → BackwaterRaw = (0.50-HPRatio)/0.49
  - [ ] 互斥区间，只有一个生效

- [ ] 2.5 实现护甲曲线
  - [ ] ArmorCurve(armor, k) = armor / (armor + k)
  - [ ] k = 50.0（配置）

**验收标准：**

- [ ] 态势计算边界正确（50%, 75%）

## 🔧 技术要点

### 需要移除的旧属性

| Character 旧属性 | 替代方案 |
|-----------------|---------|
| DamagePerAttack | CombatStats.AttackFinal |
| SpecialDamage | 移除，统一使用 AttackFinal × SkillCoef |
| CritMultiplier | 固定 1.2 + CombatStats.CritDamageBonusPercent |
| CritChancePercent | CombatStats.CritChancePercent（来自装备汇总） |

### 元素作用域规则

| Scope | 生效条件 | 典型词条 |
|-------|---------|---------|
| global | 始终生效 | HP%, Crit%, CritDmgBonus%, DR%, 固定追击 |
| element | 装备元素 == 主元素 | Attack%, SpecialAttack%, Chase%, KenChase% |
| hybrid | 按字段判断 | assault（Attack%=element, Crit%=global） |

### 伤害管线各层计算

```
1. Base = AttackFinal × SkillCoef + SkillFlat
2. Variance = Base × Random(0.95~1.05)
3. Main = Variance × (1+Atk%) × (1+SpAtk%) × (1+Stance%)
4. Crit = Main × (isCrit ? 1.2×(1+CritBonus%) : 1)
5. Element = Crit × ElementMult
6. Chase = Element + Element×Chase% + Element×KenChase% + ChaseFlat
7. Defense = Chase × (1-ArmorCurve) × (1-DR%)
```
