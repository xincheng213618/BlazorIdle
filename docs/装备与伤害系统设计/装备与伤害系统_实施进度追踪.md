# 装备与伤害系统 - 实施进度追踪

## 📋 概述

本文档用于追踪装备与伤害系统的实施进度。

**目标：** 实现完整的装备系统（主手+9副槽）、词条系统（带元素激活机制）、以及新的7层伤害计算管线。

**原则：**
- ✅ 完全替换现有伤害系统，不做向后兼容
- ✅ 配置驱动，通过 JSON 管理属性上限、词条定义、元素矩阵
- ✅ 每个阶段完成后可独立测试验证
- ✅ 移除旧的角色属性概念（如 DamagePerAttack、SpecialDamage、CritMultiplier）

- [Step5_装备系统_详细设计.md](./Step5_装备系统_详细设计.md)

## 📁 配置文件规划（参照 BlazorIdle.Shared/Config 布局）

### 新增配置文件夹：`Config/combat/`

| 文件路径 | 说明 | 阶段 |
|----------|------|------|
| `Config/combat/caps.json` | 属性上限配置（AttackPct, CritChancePct 等） | Phase 1 |
| `Config/combat/crit.json` | 暴击系统配置（基础倍率 1.2，上限等） | Phase 1 |
| `Config/combat/variance.json` | 伤害浮动配置（默认 0.95~1.05） | Phase 2 |
| `Config/combat/stance.json` | 态势配置（盛体/背水阈值与上限） | Phase 2 |

### 新增配置文件夹：`Config/elements/`

| 文件路径 | 说明 | 阶段 |
|----------|------|------|
| `Config/elements/types.json` | 元素类型定义（Fire, Water, Wind 等） | Phase 1 |
| `Config/elements/matrix.json` | 元素克制矩阵（克制 1.5，被克制 0.75） | Phase 1 |

### 新增配置文件夹：`Config/affixes/`

| 文件路径 | 说明 | 阶段 |
|----------|------|------|
| `Config/affixes/definitions.json` | 词条定义（id, name, scope, levels） | Phase 3 |
| `Config/affixes/rules.json` | 互斥/限量/唯一组规则 | Phase 3 |

### 新增配置文件夹：`Config/equipment/`

| 文件路径 | 说明 | 阶段 |
|----------|------|------|
| `Config/equipment/templates.json` | 装备模板定义（武器类型、品质、基础词条序列） | Phase 4 |
| `Config/equipment/quality.json` | 品质配置（白/绿/蓝/紫/橙词条数量、名称、颜色） | Phase 4 |
| `Config/equipment/slots.json` | 槽位配置（主手/副槽定义） | Phase 4 |

### 新增配置文件夹：`Config/reinforce/`

| 文件路径 | 说明 | 阶段 |
|----------|------|------|
| `Config/reinforce/materials.json` | 强化材料配置（Tier1-5 分层材料） | Phase 6 |
| `Config/reinforce/costs.json` | 强化成本公式（baseCost, tierFactor, stepFactor） | Phase 6 |
| `Config/reinforce/dismantle.json` | 分解产出配置（品质×Tier 基础产出） | Phase 6 |

    1. 基础层：Base = AttackFinal × SkillCoef + SkillFlat
    2. 浮动层：AfterVariance = Base × Variance
    3. 主体层：AfterMain = AfterVariance × (1+Atk%) × (1+SpAtk%) × (1+Stance%)
    4. 暴击层：AfterCrit = AfterMain × (isCrit ? 1.2×(1+CritBonus%) : 1)
    5. 元素层：AfterElement = AfterCrit × ElementMult
    6. 追击层：AfterChase = AfterElement + Chase% + KenChase% + ChaseFlat
    7. 减伤层：Final = AfterChase × (1-DR%)  ← 简化！直接使用减伤百分比

| DamagePerAttack | CombatStats.AttackFinal |
| SpecialDamage | 移除，统一使用 AttackFinal × SkillCoef |
| CritMultiplier | 固定 1.2 + CombatStats.CritDamageBonusPercent |
| CritChancePercent | CombatStats.CritChancePercent（来自装备汇总） |

### 元素作用域规则

| Scope | 生效条件 | 典型词条 |
|-------|---------|---------|
| global | 始终生效 | HP%, Crit%, CritDmgBonus%, DR%, 固定追击 |
| element | 装备元素 == 主元素 | Attack%, SpecialAttack%, Chase%, KenChase% |
| hybrid | 按字段判断 | assault（Attack%=element, Crit%=global） |

### 伤害管线各层计算

```
1. Base = AttackFinal × SkillCoef + SkillFlat
2. Variance = Base × Random(0.95~1.05)
3. Main = Variance × (1+Atk%) × (1+SpAtk%) × (1+Stance%)
4. Crit = Main × (isCrit ? 1.2×(1+CritBonus%) : 1)
5. Element = Crit × ElementMult
6. Chase = Element + Element×Chase% + Element×KenChase% + ChaseFlat
7. Defense = Chase × (1-DR%)  ← 简化！直接使用减伤百分比
```
