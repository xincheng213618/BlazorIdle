# 角色属性系统 - 实施进度追踪

## 📋 概述

本文档用于追踪角色属性系统的实施进度。

**目标：** 实现职业基础属性系统，使角色属性 = 职业基础属性 + 装备属性 + (未来)天赋加成。

**原则：**
- ✅ 职业提供基础攻击力、基础生命值、初始战斗属性
- ✅ 装备提供额外的基础属性和词条加成
- ✅ 配置驱动，通过 JSON 管理职业基础属性
- ✅ 为未来天赋系统预留扩展空间
- ✅ 保持与现有伤害管线的兼容性

**设计文档：**
- [角色属性系统_设计提案.md](./角色属性系统_设计提案.md)
- [Step6_伤害组成与计算管线.md](./Step6_伤害组成与计算管线.md) (v1.3)
- [装备与伤害系统_实施进度追踪.md](./装备与伤害系统_实施进度追踪.md)

## 🔧 技术要点

### 属性来源公式

```
最终属性 = 职业基础属性 + 装备基础属性 + 装备词条属性 + (未来)天赋加成
```

### 属性类型分类

| 属性类型 | 职业提供 | 装备提供 | 说明 |
|---------|---------|---------|------|
| 基础攻击力 | ✅ BaseAttack | ✅ 装备BaseAttack | 加法叠加 |
| 基础生命值 | ✅ BaseHP | ✅ 装备BaseHP | 加法叠加 |
| 攻击速度 | ✅ | ❌ | 职业固有，通过急速增强 |
| 暴击率% | ✅ 初始值 | ✅ 词条加成 | 叠加后裁剪 |
| 暴击伤害加成% | ✅ 初始值 | ✅ 词条加成 | 叠加后裁剪 |
| 急速% | ✅ 初始值 | ✅ 词条加成 | 叠加后裁剪 |
| 其他战斗属性 | ❌ | ✅ 词条加成 | 仅装备提供 |

### 职业差异化

| 职业 | 基础攻击力 | 基础生命 | 攻速 | 初始暴击% | 初始急速% | 特点 |
|-----|----------|---------|------|---------|---------|------|
| 战士 | 100 | 500 | 0.40 | 5% | 0% | 高生命、稳定输出 |
| 法师 | 80 | 300 | 0.35 | 10% | 0% | 高爆发、初始特攻5% |
| 盗贼 | 70 | 350 | 0.50 | 15% | 10% | 高攻速、高暴击 |
| 游侠 | 85 | 400 | 0.45 | 8% | 5% | 平衡型 |

### 与伤害管线的关系

- **无影响**：伤害管线只关心最终的 `CombatStats`
- 属性汇总在战斗开始前完成
- 管线逻辑无需修改
