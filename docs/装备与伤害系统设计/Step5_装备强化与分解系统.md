新增：强化回退（分解返还强化材料，不亏损）机制

--------------------------------
1. 改动概述
--------------------------------
在之前的“仅通用材料强化”逻辑下，强化成本不可回收，玩家若更换装备会亏损投入。v1.3 新增：分解装备时返还该装备累计用于强化的材料，使强化变成“可撤销投资”。此功能提升玩家勇于尝试与迭代的意愿，降低挫败。

--------------------------------
2. 回退机制设计目标与边界
--------------------------------
目标：
- 强化不再带永久风险 → 鼓励玩家即时强化，提高战力。
- 分解获得两部分：基础材料产出（由品质+等级决定）+ 强化投入返还。
- 不允许：通过强化-分解循环制造额外材料、跨 Tier 倒换、低级材料快速升级套利。

边界：
- 只返还通用材料（Tier 分层材料），不返还金币或其他潜在费用（若后续引入）。
- 不返还额外倍数（即无“增值”）。
- 不随市场或活动加成翻倍（活动加成仅作用基础分解部分）。

--------------------------------
3. 返还模型选项对比与推荐方案
--------------------------------
选项 A：全额同阶材料返还（推荐）  
- 强化记录每级消耗的 Tier 材料数；分解时逐级求和返还。  
- 优点：最“无负担”，逻辑清晰。  
- 风险：需防止利用 Tier 转换套利（见第6节）。

选项 B：全额返还但按当前装备等级所在 Tier 统一折算  
- 若之前跨 Tier 强化（未来可能开放），以当前 Tier 结算。  
- 风险：复杂度高，目前不需要。

选项 C：部分返还（例如 90%），留少量磨损税  
- 优点：进一步防止套利。  
- 缺点：与“无负担强化”初衷冲突。

结论：采用选项 A（全额同阶返还）+ 套利防护。

--------------------------------
4. 强化投入追踪数据结构
--------------------------------
新增字段（装备运行态或持久化）：
```json
{
  "reinforceInvestment": {
    "totalLevelsApplied": 2,
    "entries": [
      { "toLevel": 1, "tier": "Tier2", "materialUsed": 130 },
      { "toLevel": 2, "tier": "Tier2", "materialUsed": 182 }
    ]
  }
}
```
说明：
- entries 按升级步骤追加（顺序性，易于审计）。
- materialUsed 为本次从 +k → +(k+1) 的实际消耗（已含 baseCost×tierFactor×stepFactor）。
- totalLevelsApplied 用于快速判断是否有强化（0=未强化）。

--------------------------------
5. 分解结果组成（基础产出 vs 强化返还）
--------------------------------
分解后所得：
1) 基础产出：根据质量 + levelTier → dismantleYieldByQuality × tierMultiplier（保持 v1.2 规则）
2) 强化返还：Σ(entries.materialUsed) 按各 entry.tier 分类入库（无折损）

最终：
- 白装：仍无强化 → 仅出售金币（保持简洁）
- 已强化装备：基础产出 + 强化返还（不受活动加成与分解加成影响）

--------------------------------
6. 防套利策略与约束
--------------------------------
防护要点：
- 只允许在同一 Tier 装备上进行强化（当前设计是这样）；若未来开放跨 Tier 强化，禁止跨 Tier 转换返还占优。
- 禁止借“材料上行合成 → 强化 → 拆分高阶 → 分解返还”获得净增：  
  - 原则：所有材料转换环节保持损耗（上行 5→1），强化不改变 Tier 或数量倍数。  
  - 强化返还为原始投入的同 Tier 材料，不附加倍数，无法得到更高阶材料。
- 活动加成只作用基础分解，不作用强化返还，避免利用活动临时加成放大返还。

可选额外限制（若后期出现套利苗头）：
- 强化后短时间（冷却时间，如 10 分钟）分解 → 返还比例衰减（例如 70%），防闪电套利。
- 强化返还记录加哈希校验，防止客户端伪造 entries。

--------------------------------
7. 详细规则（推荐实施版）
--------------------------------
规则：
1) 强化时：追加 reinforceInvestment.entries 记录（toLevel、tier、materialUsed）。
2) 分解时：
   - 读取 reinforceInvestment.entries
   - 对每条累积 materialUsed 按 tier 汇总
   - 返还材料到玩家库存（AddMaterial(tier, amount)）
   - 移除该装备（删除运行态）
3) 不允许：在未强化的装备中出现空 entries（可用空数组）。
4) 重复强化到上限 +3：记录 3 条；分解时一次性归还。

伪代码：
```csharp
Dismantle(equipment):
    baseYield = CalcBaseYield(equipment.quality, equipment.levelTier)
    AddMaterial(equipment.levelTier, baseYield)

    if (equipment.reinforceInvestment.entries.Any()):
        foreach (var group in entries.GroupBy(e => e.tier))
            AddMaterial(group.Key, group.Sum(e => e.materialUsed))

    RemoveEquipment(equipment.id)
```

--------------------------------
8. 示例计算流程
--------------------------------
例：橙装（等级14 → Tier2），强化到 +2，然后分解
- 强化记录：
  - +0→+1：tier=Tier2, materialUsed=130
  - +1→+2：tier=Tier2, materialUsed=182
- 基础分解产出：Legendary dismantleYield=28（假设 tierMultiplier=1.0）
- 分解总收益：
  - 基础：Tier2 材料 28
  - 强化返还：Tier2 材料 130 + 182 = 312
  - 总计：Tier2 材料 340
- 玩家再用这些材料强化新获得的橙装 → 无资源损耗（时间与掉落为真实进度）

--------------------------------
新增：
```json

      "enabled": true,

```

11. 测试矩阵增量
--------------------------------
新增测试（建议 ≥12）：
1. 强化记录追加正确（+1/+2/+3）(3)  
2. 分解返还总量 = 强化投入之和（无偏差）(2)  
3. 未强化装备分解不返还强化部分 (1)  
4. 活动加成仅作用基础分解，不影响强化返还 (2)  
5. 多件批量分解合并返还 (2)  
6. 自动分解强化装备：强化返还仍正确 (2)  

边界测试：
- 分解空 entries（安全）
- 强化后立即分解（全额返还）
- 强化到上限 +3 → 分解返还累计精确

--------------------------------
12. 平衡调参杠杆
--------------------------------
若强化过快 → 提高 baseCost / stepFactor  
若材料囤积过多 →  
- 增加词条替换、外观转换消耗  
- 提升高阶强化（+4/+5）开放条件与成本  
若套利风险显现 → 设置 minSecondsHeldForFullRefund 或部分返还比例

--------------------------------
13. 风险与缓解
--------------------------------
| 风险 | 缓解 |
|------|------|
| 玩家无成本频繁换装备导致界面操作负担 | 提供“一键迁移强化”（后续）或推荐保留最优装备标记 |
| 材料流速过快 | 调整 dismantleYieldByQuality 或提高 stepFactor |
| 日后开放跨 Tier 强化引发材料层级套利 | 强化记录保持 tier；分解按原 tier 返还，不做统一折算 |
| 活动加成放大返还 | 已禁用活动对返还乘区影响 |

14. 未来扩展预留
--------------------------------
- 强化转移系统：新装备可消耗少量“转移核心”直接继承旧装备强化等级（不返还材料）

- 回收加成活动（只提升基础分解，不提升强化返还），作为清理低品质库存的手段
- 词条替换功能消耗强化返还的一部分（锁定再加工）

总结
v1.3 引入“全额返还强化材料”机制，使强化决策无后顾之忧，同时保持经济闭环与防套利约束。玩家只需关注：获得高品质装备→决定保留与否→用材料强化→若替换则分解回收材料继续投资新装备。此设计与放置游戏低心智、高循环、可持续优化的目标高度契合，并预留未来调参与扩展空间。
