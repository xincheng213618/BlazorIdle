# 多人战斗系统设计 - 方案D：服务器权威并行模拟模式

## 1. 方案概述

### 1.1 核心思路
**服务器和所有客户端同时运行相同的战斗**，使用统一的参数（RNG种子、角色快照、副本配置），服务器结果为最终权威，客户端结果仅用于动画展示。

### 1.2 设计理念
```
组队界面
  ↓
ABC玩家准备 → 服务器 → 统一配发参数
  ↓
战斗开始
  ├─ 服务器运行战斗（权威）
  ├─ 玩家A运行战斗（展示）
  ├─ 玩家B运行战斗（展示）
  └─ 玩家C运行战斗（展示）
  
结算时刻
  └─ 所有玩家以服务器结果为准
```

**关键创新**：
- ✨ 服务器和客户端**并行运算**，而非验证关系
- ✨ 客户端只负责**动画展示**，不影响最终结果
- ✨ 完全避开SignalR复杂性，使用简单的REST轮询
- ✨ 玩家刷新/离线时，直接从服务器恢复状态

### 1.3 与其他方案的对比

| 特性 | 方案A（混合） | 方案B（纯服务器） | 方案C（镜像） | **方案D（并行）** ⭐ |
|------|--------------|------------------|--------------|---------------------|
| 实时体验 | 仅队长 | 差（轮询延迟） | 好（本地） | **所有人都好** ✅ |
| 服务器负载 | 低（队长在线时） | 高 | 极低 | 中等 |
| 防作弊 | 需验证 | 完全权威 | 无需 | **完全权威** ✅ |
| 离线支持 | 队长重要 | 完全支持 | 完全支持 | **完全支持** ✅ |
| 实现复杂度 | 中等 | 低 | 极低 | **低** ✅ |
| 玩家协同感 | 中 | 低 | 无 | **高** ✅ |
| 结果一致性 | 需验证 | 完全一致 | 各自独立 | **完全一致** ✅ |

## 2. 详细架构设计

### 2.1 核心流程

#### 2.1.1 组队与准备阶段
```
1. 玩家ABC在组队界面准备
   └─ 选择副本、确认角色状态
   
2. 队长点击"开始战斗"
   └─ 上传队伍信息到服务器
   
3. 服务器生成战斗参数包
   ├─ 生成RNG种子
   ├─ 获取所有角色快照（装备、技能、属性）
   ├─ 加载副本配置
   ├─ 创建战斗实例ID
   └─ 锁定所有队员的角色状态
   
4. 服务器下发统一的"战斗开始指令"
   └─ 包含完整参数包（BattleStartPacket）
```

#### 2.1.2 战斗运行阶段
```
并行模式：

服务器端：
├─ 创建 MultiBattleInstance
├─ 使用统一参数（种子、角色、配置）
├─ 持续推进战斗（每100ms tick）
├─ 存储完整战斗状态
├─ 记录战斗日志和掉落
└─ 提供状态查询API

客户端A/B/C：
├─ 接收 BattleStartPacket
├─ 创建本地 MultiBattleInstance
├─ 使用相同参数运行战斗
├─ 渲染战斗动画（实时体验）
├─ 每5-10秒轮询服务器状态
└─ 检测状态偏差（可选）
```

#### 2.1.3 状态同步机制
```
客户端每5-10秒轮询服务器：

GET /api/party-battle/{battleId}/status
{
  "currentWave": 5,
  "elapsedTime": 123.5,
  "checksumHash": "abc123...",  // 可选：用于验证
  "isCompleted": false
}

客户端处理：
if (本地进度 ≈ 服务器进度) {
  // 继续本地运行，享受流畅动画
} else {
  // 本地偏差较大，可能卡顿了
  // 快速追赶或直接跳转到服务器进度
}
```

#### 2.1.4 玩家离线/刷新
```
玩家刷新页面或断线：

1. 重新连接后，调用 API 获取当前状态
   GET /api/party-battle/{battleId}/restore

2. 服务器返回完整战斗状态：
   {
     "battleStartPacket": {...},    // 初始参数
     "currentState": {...},          // 当前状态
     "elapsedTime": 234.5,          // 已经过时间
     "battleLog": [...]             // 战斗日志
   }

3. 客户端两种恢复方式：
   
   方式A：快速重放
   ├─ 使用初始参数创建战斗实例
   ├─ 加速模拟到当前时间点
   └─ 恢复正常速度继续
   
   方式B：状态重建（推荐）
   ├─ 直接反序列化当前状态
   ├─ 重建战斗实例
   └─ 继续运行
```

#### 2.1.5 战斗结算
```
战斗完成后：

服务器：
├─ 计算最终结果（服务器端为准）
├─ 分配战利品
├─ 结算经验和金币
├─ 存储到 PartyMemberRewards 表
└─ 标记战斗完成

客户端：
├─ 检测到战斗完成（轮询或本地完成）
├─ 调用结算API获取奖励
└─ 显示结算界面

如果客户端结果≠服务器结果：
└─ 玩家只会认为是"卡顿"或"延迟"
   → 不会影响体验，因为以服务器为准
```

#### 2.2.2 服务器端战斗协调器
```csharp
public class ServerBattleCoordinator : BackgroundService
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ConcurrentDictionary<Guid, ActiveBattleContext> _activeBattles;
    
    public ServerBattleCoordinator(IServiceProvider serviceProvider)
    {
        _serviceProvider = serviceProvider;
        _activeBattles = new ConcurrentDictionary<Guid, ActiveBattleContext>();
    }
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var now = DateTime.UtcNow;
            
            foreach (var battle in _activeBattles.Values)
            {
                try
                {
                    // 推进战斗
                    battle.Tick(0.1); // 100ms tick
                    
                    // 检查是否完成
                    if (battle.IsCompleted)
                    {
                        await FinalizeBattle(battle);
                        _activeBattles.TryRemove(battle.BattleId, out _);
                    }
                }
                catch (Exception ex)
                {
                    // 记录错误，但不中断其他战斗
                    Console.WriteLine($"Battle {battle.BattleId} error: {ex.Message}");
                }
            }
            
            // 100ms tick rate
            await Task.Delay(100, stoppingToken);
        }
    }
    
    public async Task<BattleStartPacket> StartPartyBattle(
        Guid partyId, 
        string dungeonId, 
        int dungeonLevel)
    {
        using var scope = _serviceProvider.CreateScope();
        var context = scope.ServiceProvider.GetRequiredService<ApplicationDbContext>();
        
        // 1. 获取队伍信息
        var party = await context.Parties
            .Include(p => p.Members)
            .FirstOrDefaultAsync(p => p.Id == partyId);
        
        if (party == null || party.Status != PartyStatus.InLobby)
            throw new InvalidOperationException("Party not ready");
        
        // 2. 生成RNG种子
        var rngSeed = Random.Shared.Next();
        
        // 3. 获取所有角色快照
        var characterSnapshots = new List<CharacterSnapshot>();
        foreach (var member in party.Members)
        {
            var character = await context.Characters
                .Include(c => c.Equipments)
                .Include(c => c.Skills)
                .FirstOrDefaultAsync(c => c.Id == member.CharacterId);
            
            if (character == null)
                throw new InvalidOperationException($"Character {member.CharacterId} not found");
            
            // 创建快照（锁定状态）
            var snapshot = CreateCharacterSnapshot(character);
            characterSnapshots.Add(snapshot);
        }
        
        // 4. 加载副本配置
        var dungeonConfig = await LoadDungeonConfig(dungeonId, dungeonLevel);
        
        // 5. 创建战斗开始数据包
        var battleId = Guid.NewGuid();
        var startPacket = new BattleStartPacket
        {
            BattleId = battleId,
            PartyId = partyId,
            StartTime = DateTime.UtcNow,
            RngSeed = rngSeed,
            RngIndex = 0,
            DungeonId = dungeonId,
            DungeonLevel = dungeonLevel,
            DungeonConfig = dungeonConfig,
            Characters = characterSnapshots,
            PartyLeaderId = party.LeaderId,
            MemberIds = party.Members.Select(m => m.CharacterId).ToList(),
            GameVersion = "1.0.0"
        };
        
        // 6. 创建服务器端战斗实例
        var battleContext = CreateBattleContext(startPacket);
        _activeBattles.TryAdd(battleId, battleContext);
        
        // 7. 更新队伍状态
        party.Status = PartyStatus.InBattle;
        party.CurrentBattleId = battleId;
        await context.SaveChangesAsync();
        
        // 8. 存储战斗开始记录
        var battleRecord = new PartyBattleSnapshot
        {
            Id = Guid.NewGuid(),
            PartyId = partyId,
            BattleId = battleId,
            SnapshotType = "START",
            SnapshotData = JsonSerializer.Serialize(startPacket),
            CreatedAt = DateTime.UtcNow
        };
        context.PartyBattleSnapshots.Add(battleRecord);
        await context.SaveChangesAsync();
        
        return startPacket;
    }
    
    private ActiveBattleContext CreateBattleContext(BattleStartPacket startPacket)
    {
        // 使用 BlazorIdle.Shared 的战斗引擎
        var rngContext = new RngContext(startPacket.RngSeed, startPacket.RngIndex);
        var clock = new Clock();
        
        // 创建玩家队伍
        var playerTeam = startPacket.Characters
            .Select(c => CreateBattleUnitFromSnapshot(c))
            .ToList();
        
        // 创建敌人队伍
        var enemyTeam = CreateEnemiesFromDungeonConfig(
            startPacket.DungeonConfig, 
            rngContext);
        
        // 创建战斗实例
        var battleInstance = new MultiBattleInstance(
            playerTeam,
            enemyTeam,
            rngContext,
            clock);
        
        return new ActiveBattleContext
        {
            BattleId = startPacket.BattleId,
            PartyId = startPacket.PartyId,
            StartPacket = startPacket,
            BattleInstance = battleInstance,
            Clock = clock,
            RngContext = rngContext,
            StartTime = startPacket.StartTime,
            BattleLog = new List<BattleLogEntry>()
        };
    }
}

public class ActiveBattleContext
{
    public Guid BattleId { get; set; }
    public Guid PartyId { get; set; }
    public BattleStartPacket StartPacket { get; set; }
    public MultiBattleInstance BattleInstance { get; set; }
    public Clock Clock { get; set; }
    public RngContext RngContext { get; set; }
    public DateTime StartTime { get; set; }
    public List<BattleLogEntry> BattleLog { get; set; }
    public bool IsCompleted => BattleInstance.IsFinished();
    
    public void Tick(double deltaTime)
    {
        Clock.Tick(deltaTime);
        BattleInstance.Update(deltaTime);
        
        // 记录关键事件
        // TODO: 捕获战斗日志
    }
    
    public BattleStatusResponse GetStatus()
    {
        return new BattleStatusResponse
        {
            BattleId = BattleId,
            CurrentWave = BattleInstance.CurrentWaveNumber,
            ElapsedTime = Clock.ElapsedTime,
            IsCompleted = IsCompleted,
            PlayerTeamStatus = GetTeamStatus(BattleInstance.PlayerTeam),
            EnemyTeamStatus = GetTeamStatus(BattleInstance.EnemyTeam),
            ChecksumHash = ComputeChecksum()
        };
    }
    
    private string ComputeChecksum()
    {
        // 简单的校验和：波次 + 时间 + 玩家总血量
        var data = $"{BattleInstance.CurrentWaveNumber}:" +
                   $"{Clock.ElapsedTime:F2}:" +
                   $"{BattleInstance.PlayerTeam.Sum(u => u.CurrentHp)}";
        
        using var sha = System.Security.Cryptography.SHA256.Create();
        var hash = sha.ComputeHash(System.Text.Encoding.UTF8.GetBytes(data));
        return Convert.ToBase64String(hash);
    }
}
```

#### 2.2.3 客户端战斗管理器
```csharp
public class ClientPartyBattleManager
{
    private readonly HttpClient _httpClient;
    private BattleStartPacket _startPacket;
    private MultiBattleInstance _battleInstance;
    private Clock _clock;
    private RngContext _rngContext;
    private Timer _syncTimer;
    private bool _isRunning;
    
    public event Action<BattleStatusResponse> OnServerSyncReceived;
    public event Action<BattleResult> OnBattleCompleted;
    
    public async Task<bool> StartBattle(Guid partyId, string dungeonId, int dungeonLevel)
    {
        try
        {
            // 1. 请求服务器开始战斗
            var response = await _httpClient.PostAsJsonAsync(
                "/api/party-battle/start",
                new { partyId, dungeonId, dungeonLevel });
            
            if (!response.IsSuccessStatusCode)
                return false;
            
            _startPacket = await response.Content.ReadFromJsonAsync<BattleStartPacket>();
            
            // 2. 使用相同参数创建本地战斗实例
            _rngContext = new RngContext(_startPacket.RngSeed, _startPacket.RngIndex);
            _clock = new Clock();
            
            var playerTeam = _startPacket.Characters
                .Select(c => CreateBattleUnitFromSnapshot(c))
                .ToList();
            
            var enemyTeam = CreateEnemiesFromDungeonConfig(
                _startPacket.DungeonConfig,
                _rngContext);
            
            _battleInstance = new MultiBattleInstance(
                playerTeam,
                enemyTeam,
                _rngContext,
                _clock);
            
            // 3. 开始本地战斗和同步
            _isRunning = true;
            StartLocalBattle();
            StartServerSync();
            
            return true;
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Failed to start battle: {ex.Message}");
            return false;
        }
    }
    
    private void StartLocalBattle()
    {
        // 本地战斗循环（用于动画展示）
        Task.Run(async () =>
        {
            var lastUpdate = DateTime.UtcNow;
            
            while (_isRunning && !_battleInstance.IsFinished())
            {
                var now = DateTime.UtcNow;
                var deltaTime = (now - lastUpdate).TotalSeconds;
                lastUpdate = now;
                
                // 更新战斗状态
                _clock.Tick(deltaTime);
                _battleInstance.Update(deltaTime);
                
                // 通知UI更新（渲染动画）
                await InvokeAsync(StateHasChanged);
                
                // ~60 FPS
                await Task.Delay(16);
            }
            
            // 本地战斗完成
            if (_battleInstance.IsFinished())
            {
                // 仍然需要等待服务器最终结果
                await FetchFinalResult();
            }
        });
    }
    
    private void StartServerSync()
    {
        // 每5秒同步一次服务器状态
        _syncTimer = new Timer(async _ =>
        {
            if (!_isRunning) return;
            
            try
            {
                var response = await _httpClient.GetAsync(
                    $"/api/party-battle/{_startPacket.BattleId}/status");
                
                if (response.IsSuccessStatusCode)
                {
                    var serverStatus = await response.Content
                        .ReadFromJsonAsync<BattleStatusResponse>();
                    
                    OnServerSyncReceived?.Invoke(serverStatus);
                    
                    // 检测偏差
                    DetectDesync(serverStatus);
                    
                    // 检查是否完成
                    if (serverStatus.IsCompleted)
                    {
                        await FetchFinalResult();
                    }
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"Sync error: {ex.Message}");
            }
        }, null, TimeSpan.Zero, TimeSpan.FromSeconds(5));
    }
    
    private void DetectDesync(BattleStatusResponse serverStatus)
    {
        var waveDiff = Math.Abs(_battleInstance.CurrentWaveNumber - serverStatus.CurrentWave);
        var timeDiff = Math.Abs(_clock.ElapsedTime - serverStatus.ElapsedTime);
        
        if (waveDiff > 1 || timeDiff > 10.0)
        {
            Console.WriteLine($"Desync detected! Wave: {waveDiff}, Time: {timeDiff:F1}s");
            Console.WriteLine("Client might be lagging, but server result will be authoritative.");
            
            // 可选：快速追赶到服务器进度
            // CatchUpToServer(serverStatus);
        }
    }
    
    private async Task FetchFinalResult()
    {
        _isRunning = false;
        _syncTimer?.Dispose();
        
        try
        {
            var response = await _httpClient.GetAsync(
                $"/api/party-battle/{_startPacket.BattleId}/result");
            
            if (response.IsSuccessStatusCode)
            {
                var result = await response.Content.ReadFromJsonAsync<BattleResult>();
                OnBattleCompleted?.Invoke(result);
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Failed to fetch result: {ex.Message}");
        }
    }
    
    public async Task RestoreFromDisconnect()
    {
        try
        {
            // 玩家刷新/断线后恢复
            var response = await _httpClient.GetAsync(
                $"/api/party-battle/{_startPacket.BattleId}/restore");
            
            if (response.IsSuccessStatusCode)
            {
                var restoreData = await response.Content
                    .ReadFromJsonAsync<BattleRestoreData>();
                
                // 方式A：快速重放（适合短时间断线）
                if (restoreData.ElapsedTime < 60)
                {
                    await FastForwardBattle(restoreData);
                }
                // 方式B：直接恢复状态（适合长时间断线）
                else
                {
                    await RestoreBattleState(restoreData);
                }
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Failed to restore: {ex.Message}");
        }
    }
    
    private async Task FastForwardBattle(BattleRestoreData restoreData)
    {
        // 使用相同参数重建战斗
        // （代码同 StartBattle）
        
        // 加速模拟到当前时间
        var targetTime = restoreData.ElapsedTime;
        while (_clock.ElapsedTime < targetTime && !_battleInstance.IsFinished())
        {
            _clock.Tick(0.1); // 快速推进
            _battleInstance.Update(0.1);
        }
        
        // 恢复正常速度
        StartLocalBattle();
        StartServerSync();
    }
    
    private async Task RestoreBattleState(BattleRestoreData restoreData)
    {
        // 直接反序列化状态
        _startPacket = restoreData.BattleStartPacket;
        
        // 从保存的状态重建战斗实例
        // TODO: 实现状态序列化/反序列化
        
        StartLocalBattle();
        StartServerSync();
    }
}
```

## 3. 方案优势分析

### 3.1 相比方案A的优势

| 方面 | 方案A（队长主导） | 方案D（并行模拟） |

## 4. 潜在问题与解决方案

### 4.1 服务器负载问题

**问题**：所有队伍都在服务器运行，负载会不会很高？

**解决方案**：
1. **批量tick优化**：
   - 100ms tick足够精确（10 ticks/秒）
   - 批量处理所有战斗，降低上下文切换
   
2. **优先级调度**：
   - 有玩家在线观看的战斗优先处理
   - 全员离线的战斗可以降低频率

3. **异步处理**：
   - 战斗计算在后台线程
   - API响应不阻塞

4. **横向扩展**：
   - 多个战斗服务器实例
   - 按partyId hash分配

**性能估算**：
- 单次战斗tick：~10ms（100个单位战斗）
- 单服务器理论容量：100战斗 × 10ms = 1秒
- 实际容量：50-100个并发战斗（考虑其他开销）

### 4.2 客户端与服务器结果不一致

**问题**：玩家看到自己"赢了"，但服务器说"输了"？

**解决方案**：
1. **概率极低**：
   - 使用相同RNG种子和参数
   - 确定性战斗引擎
   - 只要代码一致，结果必然一致

2. **玩家心理预期**：
   - UI提示："战斗结果以服务器为准"
   - 如果不一致，玩家会认为是"网络卡顿"
   - 类似其他在线游戏的"回滚"现象

3. **检测机制**：
   - 客户端定期上传checksum
   - 服务器检测异常客户端
   - 标记可能的作弊行为

4. **降级方案**：
   - 如果客户端频繁不一致
   - 可以禁用客户端动画
   - 直接显示服务器状态（降级到方案B）

### 4.3 断线后恢复的体验问题

**问题**：玩家刷新页面后，会不会错过很多内容？

**解决方案**：
1. **快速重放**（短时间断线）：
   - 使用加速tick快速模拟
   - 几秒内追上当前进度
   - 玩家感受到"快进"效果

2. **状态恢复**（长时间断线）：
   - 直接跳到当前状态
   - 显示"战斗进行中，已接管"提示
   - 提供战斗日志查看

3. **战斗回放**：
   - 保存关键事件
   - 玩家可以查看错过的部分
   - 类似"录像"功能
