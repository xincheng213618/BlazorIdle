# 阶段四：持久化集成

## 阶段目标

将属性系统与现有的心跳保存机制集成，并添加特定动作保存和手动保存功能，确保属性数据安全可靠地持久化。

## 持久化策略

根据需求，采用三层保存机制：

1. **心跳自动保存**（第一道防线）：每30秒自动保存一次
2. **特定动作保存**（第二道防线）：关键操作后立即保存
3. **手动保存按钮**（第三道防线）：玩家主动保存

**实现辅助方法**：

```csharp
public class CharacterService
{
    /// <summary>
    /// 立即保存角色数据到服务器
    /// </summary>
    /// <param name="character">要保存的角色</param>
    /// <param name="reason">保存原因（用于日志）</param>
    public async Task<bool> SaveImmediatelyAsync(CharacterData character, string reason)
    {
        try
        {
            _logger.LogInformation(
                "Immediate save triggered for character {CharacterId}, reason: {Reason}",
                character.Id, reason);

            var success = await UpdateCharacterAsync(character);

            if (success)
            {
                _logger.LogInformation(
                    "Successfully saved character {CharacterId}",
                    character.Id);
            }
            else
            {
                _logger.LogWarning(
                    "Failed to save character {CharacterId}",
                    character.Id);
            }

            return success;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex,
                "Error during immediate save for character {CharacterId}",
                character.Id);
            return false;
        }
    }
}
```

```razor
    private bool isSaving = false;
    private bool? lastSaveSuccess = null;
    private DateTime? lastSaveTime = null;

    private async Task OnSaveClicked()
    {
        var character = CharacterStateService.CurrentCharacter;

        {
            Logger.LogWarning("No character selected for manual save");
            return;
        }

        if (isSaving)
        {
            Logger.LogDebug("Save already in progress, ignoring click");
            return;

        try
        {
            isSaving = true;
            lastSaveSuccess = null;
            StateHasChanged();

            Logger.LogInformation(
                "Manual save initiated for character {CharacterId}",
                character.Id);

            // 执行保存

                character,

            lastSaveTime = DateTime.Now;

            // 3秒后清除状态提示
            await Task.Delay(3000);
            lastSaveSuccess = null;
            StateHasChanged();
        }
        catch (Exception ex)
        {
            Logger.LogError(ex, "Error during manual save");
            lastSaveSuccess = false;
        }
        finally
        {
            isSaving = false;
            StateHasChanged();
        }
    }
}
```

### 任务4.5：添加退出确认和保存

**说明**：
- 在玩家退出或关闭页面前保存
- 使用浏览器的 beforeunload 事件

**实现代码**：

创建 `BeforeUnloadService.cs`：

```csharp
using Microsoft.JSInterop;

namespace BlazorIdle.Services
{
    /// <summary>
    /// 页面关闭前处理服务
    /// </summary>
    public class BeforeUnloadService : IAsyncDisposable
    {
        private readonly IJSRuntime _jsRuntime;
        private readonly ILogger<BeforeUnloadService> _logger;
        private DotNetObjectReference<BeforeUnloadService>? _objRef;

        public BeforeUnloadService(
            IJSRuntime jsRuntime,
            ILogger<BeforeUnloadService> logger)
        {
            _jsRuntime = jsRuntime;
            _logger = logger;
        }

        public async Task InitializeAsync()
        {
            try
            {
                _objRef = DotNetObjectReference.Create(this);
                
                await _jsRuntime.InvokeVoidAsync(
                    "BlazorIdleApp.registerBeforeUnload",
                    _objRef);

                _logger.LogInformation("BeforeUnload handler registered");
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Failed to register beforeunload handler");
            }
        }

        [JSInvokable]
        public async Task<bool> OnBeforeUnloadAsync()
        {
            _logger.LogInformation("Page is about to unload, triggering save");

            // 触发保存事件
            await (BeforeUnload?.Invoke() ?? Task.CompletedTask);

            return true;
        }

        public event Func<Task>? BeforeUnload;

        public async ValueTask DisposeAsync()
        {
            if (_objRef != null)
            {
                try
                {
                    await _jsRuntime.InvokeVoidAsync(
                        "BlazorIdleApp.unregisterBeforeUnload");
                }
                catch
                {
                    // 忽略清理错误
                }

                _objRef.Dispose();
            }
        }
    }
}
```

**添加JavaScript代码**：

在 `wwwroot/index.html` 或单独的JS文件中：

```javascript

window.BlazorIdleApp.registerBeforeUnload = function(dotnetHelper) {
    window.blazorBeforeUnloadHelper = dotnetHelper;
    
    window.addEventListener('beforeunload', async function(e) {
        try {
            // 调用C#方法
            await dotnetHelper.invokeMethodAsync('OnBeforeUnloadAsync');
        } catch (error) {
            console.error('Error calling OnBeforeUnloadAsync:', error);
        }
    });
};

window.BlazorIdleApp.unregisterBeforeUnload = function() {
    window.blazorBeforeUnloadHelper = null;
};
```

**在主组件中使用**：

```csharp

@code {

    public async ValueTask DisposeAsync()

    }
}
```

## 常见问题

**Q: 三层保存会不会太冗余？**
A: 不会。心跳是常规保护，特定动作是重要操作保护，手动保存是用户主动保护。各有用处。

**Q: 如果网络断开怎么办？**
A: 保存会失败并记录日志。网络恢复后，下一次心跳会继续保存。考虑添加离线缓存机制。

**Q: BeforeUnload能保证保存成功吗？**
A: 不能100%保证。浏览器可能在保存完成前就关闭了。所以需要心跳和手动保存作为主要保护。

**Q: 手动保存和心跳保存会冲突吗？**
A: 不会。两者都是调用相同的API，后台会正确处理并发请求。
