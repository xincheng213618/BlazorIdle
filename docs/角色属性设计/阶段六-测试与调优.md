**测试场景**：

#### 6.2.1 极端等级测试

```csharp
// 测试代码
@page "/test/boundary"
@inject IProfessionAttributeService ProfessionService

<h3>边界条件测试</h3>

<pre>@testOutput</pre>

@code {
    private string testOutput = "";

    private async Task RunBoundaryTests()
    {
        testOutput = "[边界条件测试]\n\n";
        
        var config = await ProfessionService.GetConfigAsync("warrior");
        if (config == null)
        {
            testOutput += "✗ 配置加载失败\n";
            return;
        }

        // 测试1：Level 1（最小值）
        testOutput += "=== Level 1 测试 ===\n";
        var attrs1 = AttributeCalculator.Calculate(1, config);
        testOutput += ValidateAttributes(attrs1, "Level 1");

        // 测试2：Level 100（高等级）
        testOutput += "\n=== Level 100 测试 ===\n";
        var attrs100 = AttributeCalculator.Calculate(100, config);
        testOutput += ValidateAttributes(attrs100, "Level 100");

        // 测试3：Level 1000（极高等级）
        testOutput += "\n=== Level 1000 测试 ===\n";
        var attrs1000 = AttributeCalculator.Calculate(1000, config);
        testOutput += ValidateAttributes(attrs1000, "Level 1000");
        
        // 验证上限
        if (attrs1000.CritChancePercent <= 0.6)
        {
            testOutput += "✓ 暴击率上限正常 (≤60%)\n";
        }
        else
        {
            testOutput += $"✗ 暴击率超过上限: {attrs1000.CritChancePercent:P2}\n";
        }

        if (attrs1000.HastePercent <= 0.4)
        {
            testOutput += "✓ 急速上限正常 (≤40%)\n";
        }
        else
        {
            testOutput += $"✗ 急速超过上限: {attrs1000.HastePercent:P2}\n";
        }

        StateHasChanged();
    }

    private string ValidateAttributes(CalculatedAttributes attrs, string label)
    {
        var output = "";
        var hasError = false;

        if (attrs.MainStatTotal < 0)
        {
            output += $"✗ {label}: 主属性为负数 {attrs.MainStatTotal}\n";
            hasError = true;
        }

        if (attrs.DamagePerAttack < 1)
        {
            output += $"✗ {label}: 伤害过低 {attrs.DamagePerAttack}\n";
            hasError = true;
        }

        if (attrs.MaxHp < 1)
        {
            output += $"✗ {label}: 生命值过低 {attrs.MaxHp}\n";
            hasError = true;
        }

        if (attrs.CritChancePercent < 0 || attrs.CritChancePercent > 1)
        {
            output += $"✗ {label}: 暴击率异常 {attrs.CritChancePercent:P2}\n";
            hasError = true;
        }

        if (attrs.HastePercent < 0 || attrs.HastePercent > 1)
        {
            output += $"✗ {label}: 急速异常 {attrs.HastePercent:P2}\n";
            hasError = true;
        }

        if (!hasError)
        {
            output += $"✓ {label}: 所有属性正常\n";
            output += $"  主属性={attrs.MainStatTotal}, 伤害={attrs.DamagePerAttack}, " +
                     $"HP={attrs.MaxHp}, 暴击={attrs.CritChancePercent:P1}\n";
        }

        return output;
    }
}
```

**检查点**：
- [ ] Level 1 所有属性正常

### 任务6.4：性能测试

#### 6.4.1 计算性能测试

```csharp
@page "/test/performance"
@using System.Diagnostics

<h3>性能测试</h3>
<button @onclick="RunPerformanceTests">运行测试</button>
<pre>@testOutput</pre>

@code {
    private string testOutput = "";

    private async Task RunPerformanceTests()
    {
        testOutput = "[性能测试]\n\n";
        
        var config = await ProfessionService.GetConfigAsync("warrior");
        
        // 测试1：单次计算耗时
        var sw = Stopwatch.StartNew();
        var attrs = AttributeCalculator.Calculate(50, config);
        sw.Stop();
        testOutput += $"单次计算耗时: {sw.Elapsed.TotalMilliseconds:F3}ms\n";
        
        if (sw.Elapsed.TotalMilliseconds < 1)
        {
            testOutput += "✓ 性能优秀 (<1ms)\n";
        }
        else
        {
            testOutput += "✗ 性能较差 (≥1ms)\n";
        }

        // 测试2：批量计算耗时
        sw.Restart();
        for (int i = 0; i < 1000; i++)
        {
            AttributeCalculator.Calculate(i % 100 + 1, config);
        }
        sw.Stop();
        testOutput += $"\n1000次计算总耗时: {sw.Elapsed.TotalMilliseconds:F1}ms\n";
        testOutput += $"平均耗时: {sw.Elapsed.TotalMilliseconds / 1000:F3}ms\n";
        
        if (sw.Elapsed.TotalMilliseconds < 100)
        {
            testOutput += "✓ 批量性能优秀\n";
        }

        // 测试3：DPS计算耗时
        sw.Restart();
        for (int i = 0; i < 1000; i++)
        {
            AttributeCalculator.CalculateTotalDPS(attrs);
        }
        sw.Stop();
        testOutput += $"\n1000次DPS计算总耗时: {sw.Elapsed.TotalMilliseconds:F1}ms\n";

        // 测试4：内存占用
        var memoryBefore = GC.GetTotalMemory(true);
        var attrsList = new List<CalculatedAttributes>();
        for (int i = 0; i < 1000; i++)
        {
            attrsList.Add(AttributeCalculator.Calculate(i % 100 + 1, config));
        }
        var memoryAfter = GC.GetTotalMemory(false);
        var memoryUsed = (memoryAfter - memoryBefore) / 1024.0;
        testOutput += $"\n1000个属性对象内存占用: {memoryUsed:F1} KB\n";

        StateHasChanged();
    }
}
```

**性能目标**：
- [ ] 单次计算 < 1ms
- [ ] 1000次计算 < 100ms
- [ ] 1000次DPS计算 < 50ms
- [ ] 内存占用合理（< 200KB）

## 调优策略

### 数值调优

如果发现数值不平衡，按以下优先级调整：

1. **优先调整权重系数**（a, b, c, d, e）
2. **其次调整基线值**（baseDamage, baseHp等）
3. **最后调整主属性成长**（base, perLevel）

### 性能优化

如果发现性能问题：

1. **添加计算结果缓存**
2. **使用对象池减少GC**
3. **优化UI更新频率**
4. **考虑Web Worker计算**

### 用户体验优化

如果发现体验问题：

1. **增加视觉反馈**
2. **优化数值呈现**
3. **添加教程提示**
4. **改进错误消息**
