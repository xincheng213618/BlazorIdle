# 单人战斗并行模拟优化方案

## 概述

基于多人战斗方案D的成功设计，将**服务器权威并行模拟**架构应用到单人战斗系统中。核心思路：客户端和服务器同时运行战斗，服务器结果为准，客户端仅负责动画展示。

## 核心设计理念

### 现有方案的问题

**当前设计**（混合模拟策略）：
- 短时间离线（< 5分钟）：客户端本地模拟
- 中等时长（5分钟 - 1小时）：客户端模拟，服务器可选验证
- 长时间离线（> 1小时）：服务器端模拟

**存在的问题**：
1. ❌ 客户端可被修改，存在作弊风险
2. ❌ 离线结算需要复杂的切换逻辑
3. ❌ 需要多套处理流程（客户端、服务器、验证）
4. ❌ 单人和多人系统架构不统一

### 优化方案：服务器权威并行模拟

**核心思路**：
```
玩家开始战斗
    ↓
服务器创建权威战斗实例（持久化RNG种子）
    ↓
客户端和服务器并行运行
├─ 服务器：权威战斗计算（慢速tick，低负载）
└─ 客户端：动画展示（本地快速渲染）
    ↓
客户端定期同步服务器状态（5-10秒）
    ↓
结算以服务器结果为准
```

## 架构优势

### 1. 防作弊 ✅
- 服务器绝对权威，客户端无法篡改战斗结果
- 所有收益、掉落、经验由服务器计算
- 客户端只负责动画，不影响实际数据

### 2. 离线结算简化 ✅
- **不需要复杂的离线模拟**
- 玩家离线时，服务器继续以慢速tick运行战斗
- 玩家上线时，直接获取服务器当前战斗状态
- 离线时间 = 服务器战斗进度

### 3. 断线恢复优雅 ✅
- 页面刷新？直接从服务器获取当前状态
- 网络波动？本地继续播放动画，定期同步
- 玩家体验：只是"卡了一下"

### 4. 单人多人统一架构 ✅
- 单人战斗和多人战斗使用相同的设计模式
- 代码复用度更高
- 后续扩展到多人更简单

### 5. 服务器负载可控 ✅
- **玩家在线时**：服务器慢速tick（100-200ms），CPU占用低
- **玩家离线时**：进一步降速（500ms-1s），或暂停到心跳触发
- 通过调整tick频率平衡负载和响应速度

### 服务器端实现

#### ServerBattleCoordinator
```csharp
public class ServerBattleCoordinator
{
    private readonly Dictionary<Guid, ServerBattleInstance> _activeBattles;
    private readonly ILogger<ServerBattleCoordinator> _logger;
    private readonly GameDbContext _dbContext;
    
    public ServerBattleCoordinator(
        ILogger<ServerBattleCoordinator> logger,
        GameDbContext dbContext)
    {
        _logger = logger;
        _dbContext = dbContext;
        _activeBattles = new Dictionary<Guid, ServerBattleInstance>();
    }
    
    // 开始战斗
    public async Task<BattleStartPacket> StartBattleAsync(
        string characterId, 
        string dungeonId)
    {
        // 1. 加载角色和副本数据
        var character = await LoadCharacterAsync(characterId);
        var dungeon = await LoadDungeonAsync(dungeonId);
        
        // 2. 创建战斗实例
        var battleId = Guid.NewGuid();
        var rngSeed = GenerateRngSeed();
        
        var battleInstance = new ServerBattleInstance
        {
            BattleId = battleId,
            CharacterId = characterId,
            DungeonId = dungeonId,
            RngSeed = rngSeed,
            StartTime = DateTime.UtcNow,
            IsPlayerOnline = true
        };
        
        // 3. 初始化战斗引擎（使用BlazorIdle.Shared）
        battleInstance.Battle = new MultiBattleInstance(
            character: character,
            dungeon: dungeon,
            rngSeed: rngSeed
        );
        
        // 4. 保存到数据库
        await PersistBattleStateAsync(battleInstance);
        
        // 5. 添加到活跃战斗列表
        _activeBattles[battleId] = battleInstance;
        
        // 6. 启动服务器战斗循环
        _ = Task.Run(() => RunBattleLoopAsync(battleInstance));
        
        // 7. 返回启动包
        return new BattleStartPacket
        {
            BattleId = battleId,
            RngSeed = rngSeed,
            Character = CreateCharacterSnapshot(character),
            Dungeon = CreateDungeonConfig(dungeon),
            StartTime = battleInstance.StartTime,
            ServerTicks = 0
        };
    }
    
    // 服务器战斗循环
    private async Task RunBattleLoopAsync(ServerBattleInstance instance)
    {
        var tickInterval = instance.IsPlayerOnline 
            ? TimeSpan.FromMilliseconds(100)  // 玩家在线：快速tick
            : TimeSpan.FromMilliseconds(500); // 玩家离线：慢速tick
        
        while (!instance.IsCompleted)
        {
            try
            {
                // Tick战斗引擎
                instance.Battle.Tick();
                instance.ServerTicks++;
                
                // 定期保存状态（每30秒）
                if (instance.ServerTicks % 300 == 0)
                {
                    await PersistBattleStateAsync(instance);
                }
                
                // 检查战斗是否结束
                if (instance.Battle.IsCompleted())
                {
                    instance.IsCompleted = true;
                    await FinalizeBattleAsync(instance);
                    break;
                }
                
                // 等待下一个tick
                await Task.Delay(tickInterval);
                
                // 动态调整tick速率
                tickInterval = instance.IsPlayerOnline 
                    ? TimeSpan.FromMilliseconds(100)
                    : TimeSpan.FromMilliseconds(500);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Battle loop error for {BattleId}", instance.BattleId);
                await Task.Delay(TimeSpan.FromSeconds(1));
            }
        }
        
        // 清理
        _activeBattles.Remove(instance.BattleId);
    }
    
    // 获取战斗状态（客户端同步用）
    public BattleSyncPacket GetBattleState(Guid battleId)
    {
        if (!_activeBattles.TryGetValue(battleId, out var instance))
        {
            return null;
        }
        
        return new BattleSyncPacket
        {
            BattleId = battleId,
            ServerTicks = instance.ServerTicks,
            CurrentWave = instance.Battle.CurrentWave,
            PlayerHp = instance.Battle.Player.Hp,
            Enemies = instance.Battle.Enemies
                .Select(e => new EnemyState
                {
                    Index = e.Index,
                    Hp = e.Hp,
                    IsAlive = e.IsAlive
                })
                .ToList(),
            RecentLoots = instance.Battle.GetRecentLoots(),
            StateChecksum = ComputeChecksum(instance.Battle)
        };
    }
    
    // 玩家上线/离线通知
    public void SetPlayerOnlineStatus(Guid battleId, bool isOnline)
    {
        if (_activeBattles.TryGetValue(battleId, out var instance))
        {
            instance.IsPlayerOnline = isOnline;
            _logger.LogInformation(
                "Battle {BattleId} player status: {Status}",
                battleId,
                isOnline ? "Online" : "Offline"
            );
        }
    }
    
    // 持久化战斗状态
    private async Task PersistBattleStateAsync(ServerBattleInstance instance)
    {
        var stateJson = JsonSerializer.Serialize(new
        {
            BattleId = instance.BattleId,
            CharacterId = instance.CharacterId,
            DungeonId = instance.DungeonId,
            RngSeed = instance.RngSeed,
            ServerTicks = instance.ServerTicks,
            BattleState = instance.Battle.Serialize()
        });
        
        var gameState = await _dbContext.GameStates
            .FirstOrDefaultAsync(gs => 
                gs.CharacterId == instance.CharacterId && 
                gs.StateType == "Battle");
        
        if (gameState == null)
        {
            gameState = new GameState
            {
                Id = Guid.NewGuid(),
                CharacterId = instance.CharacterId,
                StateType = "Battle",
                Version = GetGameVersion()
            };
            _dbContext.GameStates.Add(gameState);
        }
        
        gameState.StateData = stateJson;
        gameState.LastHeartbeatAt = DateTime.UtcNow;
        gameState.ExpiresAt = DateTime.UtcNow.AddDays(7);
        
        await _dbContext.SaveChangesAsync();
    }
    
    // 战斗结算
    private async Task FinalizeBattleAsync(ServerBattleInstance instance)
    {
        var result = instance.Battle.GetFinalResult();
        
        // 保存收益到数据库
        await ApplyBattleRewardsAsync(
            instance.CharacterId,
            result.Gold,
            result.Exp,
            result.Loots
        );
        
        // 清理战斗状态
        await _dbContext.GameStates
            .Where(gs => 
                gs.CharacterId == instance.CharacterId && 
                gs.StateType == "Battle")
            .ExecuteDeleteAsync();
        
        _logger.LogInformation(
            "Battle {BattleId} completed. Gold: {Gold}, Exp: {Exp}",
            instance.BattleId,
            result.Gold,
            result.Exp
        );
    }
    
    private int GenerateRngSeed()
    {
        return (int)(DateTime.UtcNow.Ticks % int.MaxValue);
    }
    
    private string ComputeChecksum(MultiBattleInstance battle)
    {
        // 简单的checksum实现
        var data = $"{battle.CurrentWave}|{battle.Player.Hp}|{battle.Enemies.Count}";
        using var sha256 = SHA256.Create();
        var hash = sha256.ComputeHash(Encoding.UTF8.GetBytes(data));
        return Convert.ToBase64String(hash);
    }
}
```

### 客户端实现

#### ClientBattleManager
```csharp
public class ClientBattleManager
{
    private readonly HttpClient _httpClient;
    private readonly ILogger<ClientBattleManager> _logger;
    
    private Guid _battleId;
    private MultiBattleInstance _localBattle;
    private long _localTicks;
    private CancellationTokenSource _syncCts;
    
    public ClientBattleManager(
        HttpClient httpClient,
        ILogger<ClientBattleManager> logger)
    {
        _httpClient = httpClient;
        _logger = logger;
    }
    
    // 开始战斗
    public async Task<bool> StartBattleAsync(string characterId, string dungeonId)
    {
        try
        {
            // 1. 请求服务器开始战斗
            var response = await _httpClient.PostAsJsonAsync(
                "/api/battle/start",
                new { CharacterId = characterId, DungeonId = dungeonId }
            );
            
            if (!response.IsSuccessStatusCode)
            {
                return false;
            }
            
            var startPacket = await response.Content
                .ReadFromJsonAsync<BattleStartPacket>();
            
            // 2. 初始化本地战斗（使用服务器的参数）
            _battleId = startPacket.BattleId;
            _localBattle = new MultiBattleInstance(
                character: CreateCharacter(startPacket.Character),
                dungeon: CreateDungeon(startPacket.Dungeon),
                rngSeed: startPacket.RngSeed // 关键：使用服务器的种子
            );
            _localTicks = 0;
            
            // 3. 启动本地战斗循环
            _ = Task.Run(() => RunLocalBattleLoopAsync());
            
            // 4. 启动服务器同步循环
            _syncCts = new CancellationTokenSource();
            _ = Task.Run(() => SyncWithServerLoopAsync(_syncCts.Token));
            
            return true;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to start battle");
            return false;
        }
    }
    
    // 本地战斗循环（快速，用于动画）
    private async Task RunLocalBattleLoopAsync()
    {
        var tickInterval = TimeSpan.FromMilliseconds(16); // 60 FPS
        
        while (!_localBattle.IsCompleted())
        {
            try
            {
                // Tick本地战斗
                _localBattle.Tick();
                _localTicks++;
                
                // 触发UI更新事件
                OnBattleUpdated?.Invoke();
                
                // 等待下一帧
                await Task.Delay(tickInterval);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Local battle loop error");
                await Task.Delay(TimeSpan.FromSeconds(1));
            }
        }
        
        // 战斗结束，停止同步
        _syncCts?.Cancel();
        
        // 显示战斗结果
        await ShowBattleResultAsync();
    }
    
    // 服务器同步循环
    private async Task SyncWithServerLoopAsync(CancellationToken cancellationToken)
    {
        var syncInterval = TimeSpan.FromSeconds(5); // 每5秒同步一次
        var lastSyncTicks = 0L;
        
        while (!cancellationToken.IsCancellationRequested)
        {
            try
            {
                await Task.Delay(syncInterval, cancellationToken);
                
                // 获取服务器状态
                var serverState = await _httpClient.GetFromJsonAsync<BattleSyncPacket>(
                    $"/api/battle/{_battleId}/sync",
                    cancellationToken
                );
                
                if (serverState == null)
                {
                    continue;
                }
                
                // 检测偏差
                var tickDrift = Math.Abs(serverState.ServerTicks - _localTicks);
                
                if (tickDrift > 100) // 偏差超过100 ticks（约1.6秒）
                {
                    _logger.LogWarning(
                        "Large tick drift detected: {Drift} ticks. Syncing...",
                        tickDrift
                    );
                    
                    // 重新同步
                    await RestoreFromServerStateAsync(serverState);
                }
                
                lastSyncTicks = serverState.ServerTicks;
            }
            catch (OperationCanceledException)
            {
                break;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Sync loop error");
                await Task.Delay(TimeSpan.FromSeconds(1), cancellationToken);
            }
        }
    }
    
    // 从服务器状态恢复
    private async Task RestoreFromServerStateAsync(BattleSyncPacket serverState)
    {
        try
        {
            // 方案1：快速重放（小偏差）
            if (Math.Abs(serverState.ServerTicks - _localTicks) < 500)
            {
                // 从当前状态快速追赶到服务器状态
                var targetTicks = serverState.ServerTicks;
                while (_localTicks < targetTicks && !_localBattle.IsCompleted())
                {
                    _localBattle.Tick();
                    _localTicks++;
                }
            }
            else
            {
                // 方案2：直接恢复状态（大偏差）
                _localBattle.RestoreFromSnapshot(
                    wave: serverState.CurrentWave,
                    playerHp: serverState.PlayerHp,
                    enemies: serverState.Enemies
                );
                _localTicks = serverState.ServerTicks;
            }
            
            _logger.LogInformation("Battle state restored from server");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to restore from server state");
        }
    }
    
    // 显示战斗结果（从服务器获取）
    private async Task ShowBattleResultAsync()
    {
        try
        {
            var result = await _httpClient.GetFromJsonAsync<BattleResult>(
                $"/api/battle/{_battleId}/result"
            );
            
            // 显示结算界面
            OnBattleCompleted?.Invoke(result);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to get battle result");
        }
    }
    
    // 断线重连恢复
    public async Task RestoreFromDisconnectAsync(Guid battleId)
    {
        try
        {
            _battleId = battleId;
            
            // 从服务器获取当前状态
            var serverState = await _httpClient.GetFromJsonAsync<BattleSyncPacket>(
                $"/api/battle/{_battleId}/sync"
            );
            
            if (serverState == null)
            {
                _logger.LogWarning("Battle {BattleId} not found on server", battleId);
                return;
            }
            
            // 获取初始参数
            var startPacket = await _httpClient.GetFromJsonAsync<BattleStartPacket>(
                $"/api/battle/{_battleId}/info"
            );
            
            // 重建本地战斗
            _localBattle = new MultiBattleInstance(
                character: CreateCharacter(startPacket.Character),
                dungeon: CreateDungeon(startPacket.Dungeon),
                rngSeed: startPacket.RngSeed
            );
            
            // 恢复到服务器状态
            await RestoreFromServerStateAsync(serverState);
            
            // 重启战斗循环
            _ = Task.Run(() => RunLocalBattleLoopAsync());
            
            _syncCts = new CancellationTokenSource();
            _ = Task.Run(() => SyncWithServerLoopAsync(_syncCts.Token));
            
            _logger.LogInformation("Battle restored from disconnect");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to restore battle from disconnect");
        }
    }
    
    public event Action OnBattleUpdated;
    public event Action<BattleResult> OnBattleCompleted;
}
```

## 性能优化策略

### 1. 动态Tick频率调整

**玩家在线**：
- 服务器：100ms tick（每秒10次）
- 客户端：16ms tick（每秒60次，流畅动画）

**玩家离线**：
- 服务器：500ms-1000ms tick（每秒1-2次）
- 进一步优化：仅在心跳触发时计算一批ticks

### 2. 批量Tick处理

玩家离线1小时后上线，不需要逐个tick模拟：
```csharp
public void FastForwardBattle(int targetTicks)
{
    // 批量处理，跳过中间状态
    for (int i = 0; i < targetTicks; i += 10)
    {
        _battle.Tick();
        // 只记录关键事件（掉落、波次完成等）
    }
}
```

### 3. 战斗实例池

复用战斗实例对象，减少GC压力：
```csharp
private readonly ObjectPool<MultiBattleInstance> _battlePool;

public ServerBattleInstance CreateBattle()
{
    var battle = _battlePool.Get();
    // 初始化...
    return battle;
}

public void ReturnBattle(MultiBattleInstance battle)
{
    battle.Reset();
    _battlePool.Return(battle);
}
```

### 4. 服务器负载监控

当服务器负载过高时，自动调整策略：
```csharp
if (_activeBattles.Count > 1000)
{
    // 降低tick频率
    defaultTickInterval = TimeSpan.FromMilliseconds(200);
    
    // 优先处理在线玩家
    foreach (var battle in _activeBattles.Values.Where(b => b.IsPlayerOnline))
    {
        // 正常速率处理
    }
    
    // 暂停离线玩家战斗，等待下次心跳
    foreach (var battle in _activeBattles.Values.Where(b => !b.IsPlayerOnline))
    {
        battle.Pause();
    }
}
```

## 离线结算优化

### 现有流程（复杂）
1. 玩家离线
2. 客户端停止运算
3. 玩家上线时，请求服务器模拟离线期间
4. 服务器快速模拟N小时的战斗
5. 返回结果

### 优化后流程（简单）
1. 玩家离线
2. **服务器继续慢速运算**（或暂停到心跳）
3. 玩家上线时，**直接获取服务器当前状态**
4. 客户端从该状态继续展示

**代码示例**：
```csharp
// 玩家登录时检查是否有进行中的战斗
[HttpGet("check-ongoing")]
public async Task<ActionResult<OngoingBattleInfo>> CheckOngoingBattle(
    [FromQuery] string characterId)
{
    var gameState = await _dbContext.GameStates
        .FirstOrDefaultAsync(gs => 
            gs.CharacterId == characterId && 
            gs.StateType == "Battle");
    
    if (gameState == null)
    {
        return Ok(null); // 没有进行中的战斗
    }
    
    var battleData = JsonSerializer.Deserialize<BattleData>(gameState.StateData);
    
    // 检查战斗是否还在活跃列表
    var battleState = _coordinator.GetBattleState(battleData.BattleId);
    
    return Ok(new OngoingBattleInfo
    {
        BattleId = battleData.BattleId,
        OfflineDuration = DateTime.UtcNow - gameState.LastHeartbeatAt,
        CurrentWave = battleState?.CurrentWave ?? battleData.LastWave,
        // 服务器已经计算好的进度
    });
}
```

```csharp
public abstract class BaseBattleCoordinator
{

        Guid battleId,
        MultiBattleInstance battle,
        Func<bool> shouldContinue)
    {
        while (shouldContinue())
        {
            battle.Tick();
            await PersistIfNeededAsync(battleId, battle);
            await Task.Delay(GetTickInterval());
        }
    }

}
```

## 对比总结

### 优化前 vs 优化后

| 特性 | 优化前（混合模拟） | 优化后（并行模拟） |
|------|------------------|------------------|
| 防作弊 | 部分（需验证） | ✅ 完全（服务器权威） |
| 离线结算 | 复杂（多套逻辑） | ✅ 简单（直接获取） |
| 断线恢复 | 需要重新模拟 | ✅ 即时恢复 |
| 单人多人统一 | ❌ 不同架构 | ✅ 统一架构 |
| 开发复杂度 | 中等 | ✅ 低（复用多） |
| 服务器负载 | 低（仅长时间离线） | 可控（动态调整） |
| 玩家体验 | 好 | ✅ 更好（无缝） |

### 推荐理由

1. ✅ **架构统一**：单人和多人使用相同设计，后续扩展更简单
2. ✅ **开发效率**：实现单人后，多人只需扩展，复用度高
3. ✅ **玩家体验**：断线恢复更流畅，离线收益更直观
4. ✅ **防作弊**：服务器绝对权威，客户端无法篡改
5. ✅ **维护成本**：一套逻辑，两种模式，降低维护负担

## 结论

**强烈推荐采用服务器权威并行模拟架构**，原因如下：

1. 与多人战斗方案D架构一致，代码复用度高
2. 防作弊能力更强，服务器结果绝对权威
3. 离线结算逻辑大幅简化
4. 断线恢复体验更好
5. 为后续扩展多人功能打下基础

**实施建议**：
- 先完成单人战斗的并行模拟重构（3周）
- 充分测试单人模式的稳定性和性能
- 再基于相同架构扩展多人战斗（5周）
- 总时间8周，比分别实现节省3-4周

这样既保证了单人系统的质量，又为多人系统铺平了道路，是性价比最高的方案！
