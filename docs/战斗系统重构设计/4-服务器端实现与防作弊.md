# 多人战斗系统设计 - 第四部分：服务器端实现与防作弊

## 1. 服务器端职责概述

### 1.1 核心职责
1. **验证战斗快照**：检测异常数据，防止作弊
2. **分发收益**：公平分配掉落物给所有队员
3. **托管战斗**：队长离线时接管战斗运行
4. **管理队伍**：处理创建、邀请、加入、解散

### 1.2 信任模型
- **队长在线时**：半信任 - 验证但不重复计算
- **队长离线时**：完全权威 - 服务器运行战斗
- **队员收益**：完全权威 - 服务器分发

## 2. PartyBattleService 实现

### 2.1 战斗快照验证

```csharp
using System;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using BlazorIdle.Server.Data;
using BlazorIdle.Shared.DTOs;
using BlazorIdle.Shared.Models;

namespace BlazorIdle.Server.Services
{
    public class PartyBattleService : IPartyBattleService
    {
        private readonly GameDbContext _context;
        private readonly IPartyHostingService _hostingService;
        private readonly ILogger<PartyBattleService> _logger;
        
        public PartyBattleService(
            GameDbContext context,
            IPartyHostingService hostingService,
            ILogger<PartyBattleService> logger)
        {
            _context = context;
            _hostingService = hostingService;
            _logger = logger;
        }
        
        /// <summary>
        /// 同步战斗快照
        /// </summary>
        public async Task<SyncBattleResponse> SyncBattleSnapshotAsync(
            Guid partyId,
            int leaderId,
            PartyBattleSnapshotData snapshotData,
            List<LootItem> newLoots)
        {
            try
            {
                // 1. 验证队伍和权限
                var party = await _context.Parties
                    .Include(p => p.Members)
                    .FirstOrDefaultAsync(p => p.Id == partyId);
                
                if (party == null || party.LeaderId != leaderId)
                {
                    return new SyncBattleResponse
                    {
                        Success = false,
                        Message = "无权限或队伍不存在"
                    };
                }
                
                // 2. 验证快照数据
                var validationResult = await ValidateSnapshotAsync(snapshotData, party);
                
                if (!validationResult.IsValid)
                {
                    _logger.LogWarning(
                        "Invalid snapshot from party {PartyId}: {Reason}",
                        partyId,
                        validationResult.Reason);
                    
                    // 检测到作弊，转服务器托管
                    await _hostingService.StartHostingAsync(partyId);
                    
                    return new SyncBattleResponse
                    {
                        Success = false,
                        IsVerified = false,
                        Message = "检测到异常数据，已转服务器托管"
                    };
                }
                
                // 3. 保存快照
                var snapshot = new PartyBattleSnapshot
                {
                    PartyId = partyId,
                    SnapshotData = System.Text.Json.JsonSerializer.Serialize(snapshotData),
                    ElapsedMs = snapshotData.DungeonElapsedMs,
                    CurrentWave = snapshotData.CurrentWaveIndex,
                    TotalWaves = snapshotData.TotalWaves,
                    CompletionCount = snapshotData.CompletionCount,
                    IsVerified = true,
                    UploadedBy = leaderId,
                    CreatedAt = DateTime.UtcNow
                };
                
                _context.PartyBattleSnapshots.Add(snapshot);
                
                // 4. 记录掉落物
                foreach (var loot in newLoots)
                {
                    _context.PartyLootRecords.Add(new PartyLootRecord
                    {
                        PartyId = partyId,
                        SnapshotId = snapshot.Id,
                        ItemId = loot.ItemId,
                        Quantity = loot.Quantity,
                        DroppedAt = DateTime.UtcNow
                    });
                }
                
                // 5. 分发收益给所有在线队员
                await DistributeRewardsAsync(party, newLoots);
                
                // 6. 更新队伍同步时间
                party.LastSyncAt = DateTime.UtcNow;
                
                await _context.SaveChangesAsync();
                
                return new SyncBattleResponse
                {
                    Success = true,
                    SnapshotId = snapshot.Id,
                    IsVerified = true,
                    Message = "战斗快照已验证并保存"
                };
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error syncing battle snapshot for party {PartyId}", partyId);
                return new SyncBattleResponse
                {
                    Success = false,
                    Message = "同步失败：" + ex.Message
                };
            }
        }
        
        /// <summary>
        /// 验证战斗快照
        /// </summary>
        private async Task<SnapshotValidationResult> ValidateSnapshotAsync(
            PartyBattleSnapshotData snapshot,
            Party party)
        {
            // 1. 时间戳验证
            var timeSinceLastSync = DateTime.UtcNow - (party.LastSyncAt ?? party.StartedAt ?? DateTime.UtcNow);
            var expectedMinTime = timeSinceLastSync.TotalMilliseconds * 0.5;  // 至少过了一半的时间
            var expectedMaxTime = timeSinceLastSync.TotalMilliseconds * 2.0;  // 不能超过2倍时间
            
            if (snapshot.DungeonElapsedMs < expectedMinTime || snapshot.DungeonElapsedMs > expectedMaxTime)
            {
                return new SnapshotValidationResult
                {
                    IsValid = false,
                    Reason = $"时间异常：期望 {expectedMinTime}-{expectedMaxTime}ms，实际 {snapshot.DungeonElapsedMs}ms"
                };
            }
            
            // 2. 获取上一次快照
            var lastSnapshot = await _context.PartyBattleSnapshots
                .Where(s => s.PartyId == party.Id)
                .OrderByDescending(s => s.CreatedAt)
                .FirstOrDefaultAsync();
            
            if (lastSnapshot != null)
            {
                // 3. 进度验证：不能倒退
                if (snapshot.CurrentWaveIndex < lastSnapshot.CurrentWave && 
                    snapshot.CompletionCount <= lastSnapshot.CompletionCount)
                {
                    return new SnapshotValidationResult
                    {
                        IsValid = false,
                        Reason = "进度倒退"
                    };
                }
                
                // 4. 伤害验证：检查是否合理
                var damageValidation = ValidateDamage(snapshot, party);
                if (!damageValidation.IsValid)
                {
                    return damageValidation;
                }
            }
            
            // 5. 血量验证：不能超过最大值
            foreach (var character in snapshot.Characters)
            {
                if (character.CurrentHp > character.MaxHp)
                {
                    return new SnapshotValidationResult
                    {
                        IsValid = false,
                        Reason = $"角色 {character.CharacterId} 血量超过最大值"
                    };
                }
            }
            
            return new SnapshotValidationResult { IsValid = true };
        }
        
        /// <summary>
        /// 验证伤害是否合理
        /// </summary>
        private SnapshotValidationResult ValidateDamage(
            PartyBattleSnapshotData snapshot,
            Party party)
        {
            // 计算理论最大DPS
            var totalTheoricalDps = 0.0;
            
            foreach (var character in snapshot.Characters)
            {
                // 假设从角色数据获取属性
                // 这里需要查询数据库获取角色的攻击属性
                // 简化：假设每个角色100 DPS
                totalTheoricalDps += 100;
            }
            
            // 允许150%的误差（考虑暴击、随机因素）
            var maxAllowedDamage = totalTheoricalDps * (snapshot.DungeonElapsedMs / 1000.0) * 1.5;
            
            var totalDamage = snapshot.Characters.Sum(c => c.DamageDealt);
            
            if (totalDamage > maxAllowedDamage)
            {
                return new SnapshotValidationResult
                {
                    IsValid = false,
                    Reason = $"伤害异常：实际 {totalDamage}，理论最大 {maxAllowedDamage}"
                };
            }
            
            return new SnapshotValidationResult { IsValid = true };
        }
        
        /// <summary>
        /// 分发收益给所有队员
        /// </summary>
        private async Task DistributeRewardsAsync(Party party, List<LootItem> loots)
        {
            var now = DateTime.UtcNow;
            
            // 给所有活跃队员分发收益
            var activeMembers = party.Members
                .Where(m => m.Status != MemberStatus.Left)
                .ToList();
            
            foreach (var member in activeMembers)
            {
                foreach (var loot in loots)
                {
                    _context.PartyMemberRewards.Add(new PartyMemberReward
                    {
                        PartyId = party.Id,
                        MemberId = member.Id,
                        UserId = member.UserId,
                        CharacterId = member.CharacterId,
                        ItemId = loot.ItemId,
                        Quantity = loot.Quantity,
                        EarnedAt = now
                    });
                }
            }
            
            _logger.LogInformation(
                "Distributed {LootCount} items to {MemberCount} members in party {PartyId}",
                loots.Count,
                activeMembers.Count,
                party.Id);
        }
        
        /// <summary>
        /// 领取收益
        /// </summary>
        public async Task<ClaimRewardsResponse> ClaimRewardsAsync(
            Guid partyId,
            int userId,
            string characterId)
        {
            try
            {
                // 1. 获取未领取的收益
                var rewards = await _context.PartyMemberRewards
                    .Where(r => r.PartyId == partyId 
                             && r.UserId == userId 
                             && r.CharacterId == characterId
                             && r.ClaimedAt == null)
                    .ToListAsync();
                
                if (rewards.Count == 0)
                {
                    return new ClaimRewardsResponse
                    {
                        Success = true,
                        Rewards = new List<LootItem>(),
                        Message = "没有待领取的收益"
                    };
                }
                
                // 2. 合并相同物品
                var lootDict = new Dictionary<string, int>();
                foreach (var reward in rewards)
                {
                    if (!lootDict.ContainsKey(reward.ItemId))
                        lootDict[reward.ItemId] = 0;
                    lootDict[reward.ItemId] += reward.Quantity;
                }
                
                // 3. 添加到角色背包
                var character = await _context.Characters
                    .FirstOrDefaultAsync(c => c.Id == characterId && c.UserId == userId);
                
                if (character == null)
                {
                    return new ClaimRewardsResponse
                    {
                        Success = false,
                        Message = "角色不存在"
                    };
                }
                
                foreach (var loot in lootDict)
                {
                    character.Inventory.AddItem(loot.Key, loot.Value);
                }
                
                // 4. 标记为已领取
                var now = DateTime.UtcNow;
                foreach (var reward in rewards)
                {
                    reward.ClaimedAt = now;
                }
                
                await _context.SaveChangesAsync();
                
                var result = lootDict.Select(kv => new LootItem
                {
                    ItemId = kv.Key,
                    Quantity = kv.Value
                }).ToList();
                
                _logger.LogInformation(
                    "User {UserId} claimed {Count} items from party {PartyId}",
                    userId,
                    result.Count,
                    partyId);
                
                return new ClaimRewardsResponse
                {
                    Success = true,
                    Rewards = result,
                    Message = "收益已领取"
                };
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error claiming rewards");
                return new ClaimRewardsResponse
                {
                    Success = false,
                    Message = "领取失败：" + ex.Message
                };
            }
        }
    }
    
    /// <summary>
    /// 快照验证结果
    /// </summary>
    public class SnapshotValidationResult
    {
        public bool IsValid { get; set; }
        public string Reason { get; set; } = string.Empty;
    }
}
```

## 3. PartyHostingService 实现（服务器托管）

### 3.1 托管服务核心

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using BlazorIdle.Server.Data;
using BlazorIdle.Shared.Game;
using BlazorIdle.Shared.DTOs;
using BlazorIdle.Shared.Models;

namespace BlazorIdle.Server.Services
{
    public class PartyHostingService : IPartyHostingService
    {
        private readonly GameDbContext _context;
        private readonly IGameConfigService _gameConfig;
        private readonly ILogger<PartyHostingService> _logger;
        
        // 托管的战斗实例（内存中）
        private readonly Dictionary<Guid, HostedPartyBattle> _hostedBattles = new();
        private readonly object _lock = new object();
        
        public PartyHostingService(
            GameDbContext context,
            IGameConfigService gameConfig,
            ILogger<PartyHostingService> logger)
        {
            _context = context;
            _gameConfig = gameConfig;
            _logger = logger;
        }
        
        /// <summary>
        /// 开始托管
        /// </summary>
        public async Task StartHostingAsync(Guid partyId)
        {
            try
            {
                _logger.LogInformation("Starting hosting for party {PartyId}", partyId);
                
                // 1. 加载队伍信息
                var party = await _context.Parties
                    .Include(p => p.Members)
                    .ThenInclude(m => m.Character)
                    .FirstOrDefaultAsync(p => p.Id == partyId);
                
                if (party == null)
                {
                    _logger.LogError("Party not found: {PartyId}", partyId);
                    return;
                }
                
                // 2. 加载最后一次战斗快照
                var lastSnapshot = await _context.PartyBattleSnapshots
                    .Where(s => s.PartyId == partyId)
                    .OrderByDescending(s => s.CreatedAt)
                    .FirstOrDefaultAsync();
                
                if (lastSnapshot == null)
                {
                    _logger.LogError("No snapshot found for party {PartyId}", partyId);
                    return;
                }
                
                var snapshotData = System.Text.Json.JsonSerializer
                    .Deserialize<PartyBattleSnapshotData>(lastSnapshot.SnapshotData);
                
                if (snapshotData == null)
                {
                    _logger.LogError("Failed to deserialize snapshot");
                    return;
                }
                
                // 3. 重建战斗实例
                var hostedBattle = await RebuildBattleAsync(party, snapshotData);
                
                if (hostedBattle == null)
                {
                    _logger.LogError("Failed to rebuild battle");
                    return;
                }
                
                // 4. 添加到托管列表
                lock (_lock)
                {
                    _hostedBattles[partyId] = hostedBattle;
                }
                
                // 5. 更新队伍状态
                party.IsHosted = true;
                await _context.SaveChangesAsync();
                
                _logger.LogInformation("Hosting started for party {PartyId}", partyId);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error starting hosting for party {PartyId}", partyId);
            }
        }
        
        /// <summary>
        /// 停止托管
        /// </summary>
        public async Task StopHostingAsync(Guid partyId)
        {
            lock (_lock)
            {
                if (_hostedBattles.TryGetValue(partyId, out var battle))
                {
                    battle.Dispose();
                    _hostedBattles.Remove(partyId);
                }
            }
            
            var party = await _context.Parties.FindAsync(partyId);
            if (party != null)
            {
                party.IsHosted = false;
                await _context.SaveChangesAsync();
            }
            
            _logger.LogInformation("Hosting stopped for party {PartyId}", partyId);
        }
        
        /// <summary>
        /// 处理所有托管的战斗（后台任务调用）
        /// </summary>
        public async Task ProcessHostedBattlesAsync()
        {
            List<Guid> partyIds;
            lock (_lock)
            {
                partyIds = _hostedBattles.Keys.ToList();
            }
            
            foreach (var partyId in partyIds)
            {
                try
                {
                    await ProcessSingleHostedBattleAsync(partyId);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "Error processing hosted battle {PartyId}", partyId);
                }
            }
        }
        
        /// <summary>
        /// 处理单个托管战斗
        /// </summary>
        private async Task ProcessSingleHostedBattleAsync(Guid partyId)
        {
            HostedPartyBattle? battle;
            lock (_lock)
            {
                if (!_hostedBattles.TryGetValue(partyId, out battle))
                    return;
            }
            
            // 推进战斗30秒
            const int advanceMs = 30000;
            const int tickMs = 100;
            var ticks = advanceMs / tickMs;
            
            for (int i = 0; i < ticks; i++)
            {
                battle.DungeonManager.AdvanceTick(tickMs);
            }
            
            // 保存快照
            var snapshot = ExtractSnapshot(partyId, battle);
            await SaveHostedSnapshotAsync(partyId, snapshot, battle.NewLoots);
            
            battle.NewLoots.Clear();
        }
        
        /// <summary>
        /// 重建战斗实例
        /// </summary>
        private async Task<HostedPartyBattle?> RebuildBattleAsync(
            Party party,
            PartyBattleSnapshotData snapshotData)
        {
            // 1. 获取副本定义
            var dungeonDef = _gameConfig.GetDungeon(snapshotData.DungeonId);
            if (dungeonDef == null)
                return null;
            
            // 2. 创建时钟和RNG
            var clock = new SimClock();
            clock.AdvanceMs(snapshotData.ClockTimeMs);
            
            var rng = new RngContext(snapshotData.RngSeed);
            rng.SetIndex(snapshotData.RngIndex);
            
            // 3. 创建玩家队伍
            var playerTeam = new BattleTeam<Character>("party_team", "队伍", TeamType.Player);
            
            foreach (var member in party.Members.Where(m => m.Status != MemberStatus.Left))
            {
                if (member.Character == null) continue;
                
                var character = CreateCharacterFromData(member.Character);
                
                // 恢复血量（从快照）
                var charState = snapshotData.Characters
                    .FirstOrDefault(c => c.CharacterId == member.CharacterId);
                if (charState != null)
                {
                    character.Hp = charState.CurrentHp;
                }
                
                playerTeam.AddMember(member.CharacterId, character, character.MaxHp);
            }
            
            // 4. 创建副本管理器
            var dungeonManager = new DungeonManager(
                dungeonDef,
                clock,
                rng,
                playerTeam,
                _gameConfig);
            
            var hostedBattle = new HostedPartyBattle
            {
                PartyId = party.Id,
                DungeonManager = dungeonManager,
                PlayerTeam = playerTeam,
                NewLoots = new List<LootItem>()
            };
            
            // 订阅掉落事件
            dungeonManager.LootDropped += (loot) =>
            {
                hostedBattle.NewLoots.Add(new LootItem
                {
                    ItemId = loot.ItemId,
                    Quantity = loot.Quantity
                });
            };
            
            dungeonManager.EnableAutoRepeat(2000);
            dungeonManager.StartDungeon();
            
            // TODO: 恢复到具体波次（需要扩展DungeonManager）
            
            return hostedBattle;
        }
        
        private Character CreateCharacterFromData(CharacterData data)
        {
            return new Character
            {
                MaxHp = data.MaxHp,
                Hp = data.MaxHp,
                AttackRateAPS = data.AttackRateAPS,
                DamagePerAttack = data.DamagePerAttack,
                HastePercent = data.HastePercent,
                SpecialIntervalSec = data.SpecialIntervalSec,
                SpecialDamage = data.SpecialDamage,
                CritChancePercent = data.CritChancePercent,
                CritMultiplier = data.CritMultiplier,
                VariancePct = data.VariancePct,
                ReviveMs = (int)(data.ReviveSec * 1000)
            };
        }
        
        private PartyBattleSnapshotData ExtractSnapshot(Guid partyId, HostedPartyBattle battle)
        {
            var dungeonSnapshot = battle.DungeonManager.GetSnapshot();
            
            // 简化版：实际需要提取完整状态
            return new PartyBattleSnapshotData
            {
                PartyId = partyId,
                DungeonElapsedMs = dungeonSnapshot.ElapsedMs,
                CurrentWaveIndex = dungeonSnapshot.CurrentWaveIndex,
                TotalWaves = dungeonSnapshot.TotalWaves,
                CompletionCount = dungeonSnapshot.CompletionCount,
                Timestamp = DateTime.UtcNow
            };
        }
        
        private async Task SaveHostedSnapshotAsync(
            Guid partyId,
            PartyBattleSnapshotData snapshot,
            List<LootItem> loots)
        {
            // 类似 PartyBattleService.SyncBattleSnapshotAsync
            // 保存快照和分发收益
            await Task.CompletedTask;
        }
    }
    
    /// <summary>
    /// 托管的战斗实例
    /// </summary>
    public class HostedPartyBattle : IDisposable
    {
        public Guid PartyId { get; set; }
        public DungeonManager DungeonManager { get; set; } = null!;
        public BattleTeam<Character> PlayerTeam { get; set; } = null!;
        public List<LootItem> NewLoots { get; set; } = new();
        
        public void Dispose()
        {
            DungeonManager?.StopDungeon();
        }
    }
}
```

### 3.2 后台托管任务

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;

namespace BlazorIdle.Server.BackgroundServices
{
    /// <summary>
    /// 后台服务：处理托管的队伍战斗
    /// </summary>
    public class PartyHostingBackgroundService : BackgroundService
    {
        private readonly IServiceProvider _serviceProvider;
        private readonly ILogger<PartyHostingBackgroundService> _logger;
        
        public PartyHostingBackgroundService(
            IServiceProvider serviceProvider,
            ILogger<PartyHostingBackgroundService> logger)
        {
            _serviceProvider = serviceProvider;
            _logger = logger;
        }
        
        protected override async Task ExecuteAsync(CancellationToken stoppingToken)
        {
            _logger.LogInformation("Party hosting background service started");
            
            while (!stoppingToken.IsCancellationRequested)
            {
                try
                {
                    await Task.Delay(30000, stoppingToken);  // 每30秒执行一次
                    
                    using var scope = _serviceProvider.CreateScope();
                    var hostingService = scope.ServiceProvider
                        .GetRequiredService<IPartyHostingService>();
                    
                    // 1. 处理所有托管的战斗
                    await hostingService.ProcessHostedBattlesAsync();
                    
                    // 2. 检测需要托管的队伍（队长离线>5分钟）
                    await DetectAndStartHostingAsync(scope);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "Error in party hosting background service");
                }
            }
            
            _logger.LogInformation("Party hosting background service stopped");
        }
        
        private async Task DetectAndStartHostingAsync(IServiceScope scope)
        {
            var context = scope.ServiceProvider.GetRequiredService<GameDbContext>();
            var hostingService = scope.ServiceProvider.GetRequiredService<IPartyHostingService>();
            
            var threshold = DateTime.UtcNow.AddMinutes(-5);
            
            // 查找需要托管的队伍：战斗中且队长超过5分钟未同步
            var partiesToHost = await context.Parties
                .Where(p => p.Status == PartyStatus.Fighting
                         && !p.IsHosted
                         && p.LastSyncAt < threshold)
                .ToListAsync();
            
            foreach (var party in partiesToHost)
            {
                _logger.LogInformation(
                    "Party {PartyId} leader inactive, starting hosting",
                    party.Id);
                
                await hostingService.StartHostingAsync(party.Id);
            }
        }
    }
}
```

## 4. 防作弊策略总结

### 4.1 多层防护

| 层级 | 策略 | 说明 |
|------|------|------|
| 1. 时间验证 | 检查快照时间戳 | 不能快进或倒退 |
| 2. 进度验证 | 检查波次和完成数 | 不能跳过内容 |
| 3. 伤害验证 | 检查总伤害量 | 不能超出理论上限 |
| 4. 数值验证 | 检查血量、属性 | 不能修改角色属性 |
| 5. 行为验证 | 异常模式检测 | 检测异常操作模式 |
| 6. 服务器托管 | 异常时接管 | 最终保障 |

### 4.2 具体检测点

```csharp
public class AnomalyDetector
{
    /// <summary>
    /// 检测异常模式
    /// </summary>
    public static List<string> DetectAnomalies(
        PartyBattleSnapshotData current,
        PartyBattleSnapshot? previous)
    {
        var anomalies = new List<string>();
        
        // 1. 时间倒流
        if (previous != null && current.DungeonElapsedMs < previous.ElapsedMs)
        {
            anomalies.Add("时间倒流");
        }
        
        // 2. 进度异常
        if (current.CurrentWaveIndex > current.TotalWaves)
        {
            anomalies.Add("波次超出总数");
        }
        
        // 3. 角色异常
        foreach (var character in current.Characters)
        {
            // 血量超出
            if (character.CurrentHp > character.MaxHp)
            {
                anomalies.Add($"角色 {character.CharacterId} 血量超出");
            }
            
            // 负血量存活
            if (character.CurrentHp <= 0 && character.IsAlive)
            {
                anomalies.Add($"角色 {character.CharacterId} 零血存活");
            }
        }
        
        // 4. 伤害异常（需要更复杂的计算）
        var totalDamage = current.Characters.Sum(c => c.DamageDealt);
        var timeSeconds = current.DungeonElapsedMs / 1000.0;
        var avgDpsPerChar = totalDamage / timeSeconds / current.Characters.Count;
        
        if (avgDpsPerChar > 1000)  // 假设单个角色不可能超过1000 DPS
        {
            anomalies.Add("伤害异常高");
        }
        
        return anomalies;
    }
}
```

### 4.3 处理流程

```
1. 收到快照 
   ↓
2. 基础验证（格式、权限）
   ↓
3. 数据验证（时间、进度、伤害）
   ↓
4a. 验证通过 → 保存快照 → 分发收益
   ↓
4b. 验证失败 → 记录日志 → 启动服务器托管
   ↓
5. 从上一个合法快照继续
```
