# 核心战斗系统重构 - 实施进度追踪

## 📋 概述

本文档用于追踪核心战斗系统重构的实施进度。

**目标：**
1. **架构优化**：将 MultiBattleInstance.cs (~3800行) 拆分为多个职责单一的模块
2. **功能扩展**：实现多段伤害机制，支持连击、延迟伤害等高级技能效果
3. **代码质量**：提高可测试性、可维护性和团队协作效率

**核心改造：**
```
当前流程（线性1:1）：
SkillResolver.Cast() → 单次伤害 → ApplyDamage()

目标流程（支持多段）：
SkillResolver.Cast() → DamageInstance[] → SkillExecutor → DamageApplier
    ├── 立即伤害：直接应用
    └── 延迟伤害：PendingDamageQueue → 定时应用
```

**原则：**
- ✅ 向后兼容：现有单段伤害技能无需修改配置
- ✅ 配置驱动：多段伤害通过 JSON 配置，无需代码修改
- ✅ 增量重构：分阶段提取模块，每阶段可独立测试验证
- ✅ 测试覆盖：确保现有 1177+ 测试通过

- [装备与伤害系统_实施进度追踪.md](../装备与伤害系统设计/装备与伤害系统_实施进度追踪.md)

## 🔧 技术要点

### 多段伤害配置格式

```json
{
  "id": "skill_id",
  "name": "技能名称",
  "hits": [
    {
      "hitIndex": 0,
      "coefAtk": 0.5,
      "flat": 0,
      "delaySec": 0,
      "independentCrit": true,
      "targetPolicy": null
    }
  ]
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `hitIndex` | int | 必填 | 击中编号，用于标识段落 |
| `coefAtk` | double | 1.0 | 攻击力系数 |
| `flat` | int | 0 | 固定伤害 |
| `delaySec` | double | 0 | 延迟秒数，0表示立即 |
| `independentCrit` | bool | true | 是否独立判定暴击 |
| `targetPolicy` | string? | null | 目标策略覆盖 |

### 向后兼容规则

```
如果 skillDef.Hits != null && skillDef.Hits.Count > 0:
    使用 Hits 列表（多段伤害）
否则如果 skillDef.Damage != null:
    转换为单个 DamageInstance（coefAtk=Damage.CoefAtk, delaySec=0）
否则:
    无伤害技能（治疗/Buff技能）
```

### 延迟伤害处理流程

```
1. SkillResolver.Cast() 计算所有 Hits
2. SkillExecutor 处理 DamageInstances:
   - DelaySec == 0 → DamageApplier.ApplyDamageInstance()
   - DelaySec > 0 → PendingDamageQueue.Enqueue()
3. MultiBattleInstance.AdvanceTick() 调用:
   - DamageApplier.ProcessPendingDamages(currentTimeSec)
4. 延迟伤害出队时检查:
   - 目标存活 → 应用伤害
   - 目标死亡 → 丢弃/记录未命中
```
