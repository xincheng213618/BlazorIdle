# 药水与食物系统 - 实施进度追踪

## 📋 概述

本文档用于追踪药水与食物消耗品系统的实施进度。

**目标：** 实现独立的药水和食物栏位系统，支持战斗中自动触发、物品真实消耗、配置化管理。

**原则：**
- ✅ 复用现有的 OnPeriodic 技能触发系统
- ✅ 配置驱动，通过 JSON 管理所有消耗品参数
- ✅ 物品真实消耗，每次使用扣除背包库存
- ✅ 角色独立配置，不相互影响
- ✅ 向后兼容，不破坏现有技能系统

**设计文档：** [药水与食物系统扩展设计.md](./药水与食物系统扩展设计.md)

## 🔧 技术要点

### 已确认的设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| **装备模式** | **引用模式（非复制）** | 槽位只保存物品ID，每次使用实时从背包扣除。玩家补充库存后自动生效，无需重新配置 |
| 触发优先级 | 先药水后食物，按槽位顺序 | potion_1 → potion_2 → food_1 → food_2 |
| 库存耗尽处理 | 保留配置，显示特殊样式 | 不自动卸载，等待玩家补充 |
| 冷却追踪方式 | 按物品ID | 同类物品共享冷却 |
| 槽位唯一性 | 禁止重复装备 | 同一物品不能装备多个槽位 |
| 战斗中修改 | 禁止 | 包括技能和物品配置 |
| 战斗中购买 | 允许 | 可在商店购买补充库存 |
| 角色配置 | 独立 | 每个角色独立消耗品配置 |
| UI交互 | 点击选择 | 不使用拖拽 |

### 消耗品分类

| 类别 | 定位 | 主要效果 |
