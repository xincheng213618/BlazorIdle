**项目：** BlazorIdle

**版本：** v1.1 已确认  
**日期：** 2025-11-26  
**状态：** ✅ 已确认

## 1. 执行概要

### 1.1 背景

当前系统中，玩家在战斗中使用药水的方式是通过将药水技能（如 `health_potion_skill`）装备在被动技能栏位中实现的。这种方案存在以下局限：
- 被动技能栏位仅有1个，无法同时装备多个药水/食物
- 药水不会真正消耗背包中的物品
- 食物系统尚未与战斗系统集成

### 1.2 目标

扩展战斗系统，实现独立的药水和食物栏位系统：
- **2个药水栏位**：用于装备战斗中使用的药水（提供持久/短期增益）
- **2个食物栏位**：用于装备战斗中使用的食物（提供瞬间/持续恢复）
- 每次使用消耗背包中对应物品
- 支持战斗前配置、战斗中自动触发
- 所有配置参数统一存放在 Shared 的 JSON 配置文件中

### 1.3 核心设计原则

1. **最小侵入性**：复用现有的技能触发系统（OnPeriodic）
2. **统一配置管理**：参数配置在JSON中，不硬编码
3. **向后兼容**：不破坏现有的技能装备系统
4. **物品真实消耗**：使用消耗品时扣除背包库存
5. **角色独立配置**：每个角色独立管理自己的消耗品配置

### 1.4 已确认的设计决策

| 问题 | 决策 |
|------|------|
| 装备模式 | **引用模式**：槽位只保存物品ID引用，每次使用时实时从背包扣除物品。玩家在战斗外购买/生产新物品后，配置界面自动反映新库存数量 |
| 触发优先级 | 先药水后食物，按槽位顺序（potion_1 → potion_2 → food_1 → food_2） |
| 库存耗尽处理 | 保留配置，显示"物品用完"样式，等待玩家补充。当玩家补充库存后自动恢复可用 |
| 冷却追踪方式 | 按物品ID追踪（同类物品共享冷却），禁止同一物品装备多个槽位 |
| 战斗中更换 | 禁止修改配置（包括技能和物品），但可在商店购买补充库存 |
| 多角色配置 | 每个角色独立消耗品配置 |
| UI交互方式 | 点击槽位显示可装备物品列表，不使用拖拽 |

## 5. 战斗逻辑实现

### 5.1 核心流程

```
ProcessPeriodicSkillChecks (每秒)
    │
    ├── ProcessCharacterPeriodicSkills (现有 - 被动技能)
    │
    └── ProcessCharacterConsumableChecks [NEW]
        │
        ├── 遍历药水槽位 (potion_1, potion_2)
        │   │
        │   ├── 槽位是否装备物品？
        │   │   └── 否 → 跳过
        │   │
        │   ├── 获取物品的触发条件
        │   │   └── 检查条件是否满足（hpBelowPct, etc.）
        │   │       └── 否 → 跳过
        │   │
        │   ├── 检查冷却
        │   │   └── 冷却中 → 跳过
        │   │
        │   ├── 检查背包库存（实时从背包读取）
        │   │   └── 库存为0 → 触发耗尽事件（保留配置，等待补充）
        │   │
        │   └── 执行消耗品使用
        │       ├── 执行关联技能
        │       ├── 从背包扣除物品 x 1（实时扣除）
        │       ├── 启动冷却
        │       └── 触发消耗品使用事件
        │
        └── 遍历食物槽位 (food_1, food_2)
            └── (同上逻辑)
```

### 5.2 MultiBattleInstance 扩展方法

```csharp
/// <summary>
/// 处理角色的消耗品检查（药水和食物）
/// Process character's consumable checks (potions and food)
/// 触发顺序：先药水后食物，按槽位顺序（potion_1 → potion_2 → food_1 → food_2）
/// </summary>
private void ProcessCharacterConsumableChecks(string characterId, int nowMs)
{
    // 获取角色数据
    if (_characterDataMap == null || !_characterDataMap.TryGetValue(characterId, out var characterData))
        return;

    // 获取消耗品装备配置
    var consumableConfig = characterData.EquippedConsumables;
    if (consumableConfig == null)
        return;

    // 创建战斗上下文
    var context = CreateBattleContext(characterId);

    // 处理药水槽位（优先触发，提供增益效果）
    foreach (var (slotId, slotData) in consumableConfig.PotionSlots.OrderBy(x => x.Key))
    {
        ProcessConsumableSlot(characterId, slotId, slotData, context, nowMs, characterData);
    }

    // 处理食物槽位（其次触发，提供恢复效果）
    foreach (var (slotId, slotData) in consumableConfig.FoodSlots.OrderBy(x => x.Key))
    {
        ProcessConsumableSlot(characterId, slotId, slotData, context, nowMs, characterData);
    }
}

/// <summary>
/// 处理单个消耗品槽位
/// Process a single consumable slot
/// </summary>
private void ProcessConsumableSlot(
    string characterId, 
    string slotId, 
    ConsumableSlotData slotData, 
    BattleContext context, 
    int nowMs,
    CharacterData characterData)
{
    // 检查槽位是否装备
    if (string.IsNullOrEmpty(slotData.ItemId) || string.IsNullOrEmpty(slotData.SkillId))
        return;

    // 获取物品配置
    var itemConfig = _itemRepository.GetItemById(slotData.ItemId);
    if (itemConfig?.ConsumableConfig == null)
        return;

    // 检查触发条件
    if (itemConfig.ConsumableConfig.TriggerConditions != null)
    {
        var tempSkill = new SkillDef { Conditions = itemConfig.ConsumableConfig.TriggerConditions };
        if (!_conditionChecker.CheckConditions(tempSkill, context, isCasterPlayer: true, characterId))
            return;
    }

    // 检查冷却（按物品ID追踪，同类物品共享冷却）
    var cooldownManager = GetOrCreateCooldownManager(characterId);
    string cooldownKey = $"consumable_{slotData.ItemId}";
    if (!cooldownManager.IsReady(cooldownKey))
        return;

    // 检查背包库存（不自动卸载，保留配置等待玩家补充）
    int currentCount = characterData.Inventory.GetItemCount(slotData.ItemId);
    if (currentCount <= 0)
    {
        // 库存不足，触发库存耗尽事件（UI可据此显示特殊样式）
        ConsumableOutOfStock?.Invoke(new ConsumableOutOfStockEvent
        {
            TimeMs = nowMs,
            CharacterId = characterId,
            ItemId = slotData.ItemId,
            SlotId = slotId
        });
        return;
    }

    // 扣除背包库存
    if (!characterData.Inventory.ConsumeItem(slotData.ItemId, 1))
        return;

    // 执行消耗品技能
    ExecuteSkill(characterId, slotData.SkillId, $"consumable_{slotId}", isCasterPlayer: true, EventSource.Consumable);

    // 启动冷却（使用物品配置的冷却时间）
    double cooldownSec = itemConfig.ConsumableConfig.CooldownSec;
    if (cooldownSec > 0)
    {
        cooldownManager.StartCooldown(cooldownKey, cooldownSec);
    }

    // 触发消耗品使用事件
    ConsumableUsed?.Invoke(new ConsumableUsedEvent
    {
        TimeMs = nowMs,
        CharacterId = characterId,
        ItemId = slotData.ItemId,
        SkillId = slotData.SkillId,
        SlotId = slotId,
        RemainingCount = characterData.Inventory.GetItemCount(slotData.ItemId)
    });
}
```

## 10. 消耗品分类标准（已确认）

### 10.1 药水类 (Potion)

**定位：** 提供持久增益或短期增益效果

| 物品ID | 名称 | 效果类型 | 效果描述 | 冷却时间 |
|--------|------|----------|----------|----------|
| `strength_potion` | 力量药水 | 短期增益 | 增加10%攻击力，持续60秒 | 120秒 |
| `speed_potion` | 敏捷药水 | 短期增益 | 增加15%攻击速度，持续60秒 | 120秒 |

> 注意：原有的 `health_potion` 和 `mana_potion` 归类为回复类，移到食物分类中或创建独立的回复药水分类。当前战斗系统没有魔力(Mana)和防御概念，相关物品暂不实现。

### 10.2 食物类 (Food)

**定位：** 提供瞬间恢复或持续恢复效果

| 物品ID | 名称 | 效果类型 | 效果描述 | 触发条件 | 冷却时间 |
|--------|------|----------|----------|----------|----------|
| `apple` | 苹果 | 瞬间恢复 | 恢复15点生命值 | HP < 70% | 15秒 |
| `bread` | 面包 | 瞬间恢复 | 恢复20点生命值 | HP < 60% | 20秒 |
| `cheese` | 奶酪 | 瞬间恢复 | 恢复30点生命值 | HP < 50% | 25秒 |
| `meat` | 烤肉 | 瞬间恢复 | 恢复40点生命值 | HP < 40% | 30秒 |
| `steak` | 牛排 | 瞬间恢复+短期增益 | 恢复80点生命值，增加5%攻击力30秒 | HP < 30% | 60秒 |
| `health_potion` | 生命药水 | 瞬间恢复 | 恢复50点生命值 | HP < 50% | 30秒 |

### 10.3 分类对比

| 类别 | 定位 | 主要效果 | 典型场景 |
|------|------|----------|----------|
| 药水 | 增益提升 | 持久/短期属性增益 | 战斗开始时使用，提升战斗力 |
| 食物 | 生命恢复 | 瞬间/持续恢复HP | 血量降低时自动触发恢复 |

## 附录

### A. 与现有系统的对比

| 特性 | 被动技能方案（现有） | 消耗品栏位方案（新） |
|------|----------------------|----------------------|
| 栏位数量 | 1个被动槽位 | 2药水+2食物 |
| 物品消耗 | 不消耗实际物品 | 每次使用消耗1个 |
| 配置灵活性 | 需学习技能书 | 直接从背包装备 |
| 冷却管理 | 技能冷却系统 | 物品专属冷却（技能冷却移除） |
| 适用场景 | 永久被动效果 | 临时消耗性效果 |

### B. 冷却时间说明

- **冷却以物品为准**：消耗品技能本身不再定义冷却时间，统一使用物品配置的 `cooldownSec`
- **共享冷却**：同一物品ID在不同槽位共享冷却（但禁止同一物品装备多个槽位）
- **独立追踪**：每个角色的冷却独立追踪，不相互影响

### C. UI交互规范

1. **栏位配置**：点击空槽位 → 弹出物品选择面板 → 显示当前背包中可装备的同类物品
2. **实时数量**：槽位上显示当前背包中该物品的剩余数量
3. **耗尽样式**：数量为0时，显示特殊样式（如灰化、红色边框）提示玩家补充
4. **禁止重复**：同一物品不能同时装备在两个槽位中
5. **战斗锁定**：战斗中禁止修改任何配置
