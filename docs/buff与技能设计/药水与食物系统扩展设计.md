## 1. 执行概要

### 1.1 背景

当前系统中，玩家在战斗中使用药水的方式是通过将药水技能（如 `health_potion_skill`）装备在被动技能栏位中实现的。这种方案存在以下局限：
- 被动技能栏位仅有1个，无法同时装备多个药水/食物
- 药水不会真正消耗背包中的物品
- 食物系统尚未与战斗系统集成

### 1.2 目标

扩展战斗系统，实现独立的药水和食物栏位系统：
- **2个药水栏位**：用于装备战斗中使用的药水
- **2个食物栏位**：用于装备战斗中使用的食物
- 每次使用消耗背包中对应物品
- 支持战斗前配置、战斗中自动触发
- 所有配置参数统一存放在 Shared 的 JSON 配置文件中

### 1.3 核心设计原则

1. **最小侵入性**：复用现有的技能触发系统（OnPeriodic）
2. **统一配置管理**：参数配置在JSON中，不硬编码
3. **向后兼容**：不破坏现有的技能装备系统
4. **物品真实消耗**：使用消耗品时扣除背包库存

## 3. 数据模型设计

### 3.1 新增配置类

#### 3.1.1 ConsumableSlotData（消耗品槽位数据）

```csharp
namespace BlazorIdle.Shared.Models
{
    /// <summary>
    /// 消耗品槽位数据 - 存储单个槽位的装备信息
    /// Consumable slot data - stores equipment info for a single slot
    /// </summary>
    public sealed class ConsumableSlotData
    {
        /// <summary>
        /// 装备的物品ID（对应 items.json 中的 id）
        /// Equipped item ID (corresponds to id in items.json)
        /// </summary>
        [JsonPropertyName("itemId")]
        public string? ItemId { get; set; }

        /// <summary>
        /// 关联的技能ID（对应 consumableSkills.json 中的 id）
        /// Associated skill ID (corresponds to id in consumableSkills.json)
        /// </summary>
        [JsonPropertyName("skillId")]
        public string? SkillId { get; set; }
    }
}
```

## 5. 战斗逻辑实现

### 5.1 核心流程

```
ProcessPeriodicSkillChecks (每秒)
    │
    ├── ProcessCharacterPeriodicSkills (现有 - 被动技能)
    │
    └── ProcessCharacterConsumableChecks [NEW]
        │
        ├── 遍历药水槽位 (potion_1, potion_2)
        │   │
        │   ├── 槽位是否装备物品？
        │   │   └── 否 → 跳过
        │   │
        │   ├── 获取物品的触发条件
        │   │   └── 检查条件是否满足（hpBelowPct, etc.）
        │   │       └── 否 → 跳过
        │   │
        │   ├── 检查冷却
        │   │   └── 冷却中 → 跳过
        │   │
        │   ├── 检查背包库存
        │   │   └── 库存为0 → 自动卸载槽位
        │   │
        │   └── 执行消耗品使用
        │       ├── 执行关联技能
        │       ├── 扣除背包物品 x 1
        │       ├── 启动冷却
        │       └── 触发消耗品使用事件
        │
        └── 遍历食物槽位 (food_1, food_2)
            └── (同上逻辑)
```

### 5.2 MultiBattleInstance 扩展方法

```csharp
/// <summary>
/// 处理角色的消耗品检查（药水和食物）
/// Process character's consumable checks (potions and food)
/// </summary>
private void ProcessCharacterConsumableChecks(string characterId, int nowMs)
{
    // 获取角色数据
    if (_characterDataMap == null || !_characterDataMap.TryGetValue(characterId, out var characterData))
        return;

    // 获取消耗品装备配置
    var consumableConfig = characterData.EquippedConsumables;
    if (consumableConfig == null)
        return;

    // 创建战斗上下文
    var context = CreateBattleContext(characterId);

    // 处理药水槽位
    foreach (var (slotId, slotData) in consumableConfig.PotionSlots)
    {
        ProcessConsumableSlot(characterId, slotId, slotData, context, nowMs, characterData);
    }

    // 处理食物槽位
    foreach (var (slotId, slotData) in consumableConfig.FoodSlots)
    {
        ProcessConsumableSlot(characterId, slotId, slotData, context, nowMs, characterData);
    }
}

/// <summary>
/// 处理单个消耗品槽位
/// Process a single consumable slot
/// </summary>
private void ProcessConsumableSlot(
    string characterId, 
    string slotId, 
    ConsumableSlotData slotData, 
    BattleContext context, 
    int nowMs,
    CharacterData characterData)
{
    // 检查槽位是否装备
    if (string.IsNullOrEmpty(slotData.ItemId) || string.IsNullOrEmpty(slotData.SkillId))
        return;

    // 获取物品配置
    var itemConfig = _itemRepository.GetItemById(slotData.ItemId);
    if (itemConfig?.ConsumableConfig == null)
        return;

    // 检查触发条件
    if (itemConfig.ConsumableConfig.TriggerConditions != null)
    {
        var tempSkill = new SkillDef { Conditions = itemConfig.ConsumableConfig.TriggerConditions };
        if (!_conditionChecker.CheckConditions(tempSkill, context, isCasterPlayer: true, characterId))
            return;
    }

    // 检查冷却
    var cooldownManager = GetOrCreateCooldownManager(characterId);
    string cooldownKey = $"consumable_{slotData.ItemId}";
    if (!cooldownManager.IsReady(cooldownKey))
        return;

    // 检查并扣除背包库存
    if (!characterData.Inventory.ConsumeItem(slotData.ItemId, 1))
    {
        // 库存不足，自动卸载槽位
        slotData.ItemId = null;
        slotData.SkillId = null;
        return;
    }

    // 执行消耗品技能
    ExecuteSkill(characterId, slotData.SkillId, $"consumable_{slotId}", isCasterPlayer: true, EventSource.Consumable);

    // 启动冷却
    double cooldownSec = itemConfig.ConsumableConfig.CooldownSec;
    if (cooldownSec > 0)
    {
        cooldownManager.StartCooldown(cooldownKey, cooldownSec);
    }

    // 触发消耗品使用事件
    ConsumableUsed?.Invoke(new ConsumableUsedEvent
    {
        TimeMs = nowMs,
        CharacterId = characterId,
        ItemId = slotData.ItemId,
        SkillId = slotData.SkillId,
        SlotId = slotId,
        RemainingCount = characterData.Inventory.GetItemCount(slotData.ItemId)
    });
}
```
