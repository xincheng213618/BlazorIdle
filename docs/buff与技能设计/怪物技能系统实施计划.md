## 📋 文档概述

**创建日期：** 2025-11-17  
**创建者：** GitHub Copilot  
**状态：** ✅ 准备实施  
**目标：** 将怪物攻击系统迁移到新的技能系统（简化版本，仅固定普通攻击）

## 🎯 项目背景

### 当前状态
- ✅ **玩家技能系统**：已完成 Step2 Phase3+ 整合
  - Character 实体通过 `GetNormalAttackSkillId()` 和 `GetSpecialAttackSkillId()` 获取技能ID
  - `ExecuteSkill()` 统一执行技能逻辑
  - skills.json 配置驱动
- ⚠️ **怪物攻击系统**：仍使用旧系统
  - `ProcessEnemyAttackViaSkillResolver()` 硬编码 `SkillIds.EnemyAttackBasic`
  - 无法配置不同怪物的攻击特性
  - 未来扩展困难

### 设计决策
根据用户反馈，采用**简化方案**，遵循 P3 玩家攻击集成模式：
1. **当前阶段**：只实现固定普通攻击（不包含触发技能）
2. **未来扩展**：阶段7实现触发技能时，自然支持怪物触发逻辑
3. **代码复用**：直接复用 `ExecuteSkill()` 函数（不创建单独的怪物函数）

**技能参数说明：**

| 参数 | 值 | 说明 |
|------|-----|------|
| id | "enemy_attack_basic" | 所有怪物共享的通用技能ID |
| name | "怪物普通攻击" | 通用名称 |
| type | "passive" | 被动技能（自动触发） |
| slotType | "passive" | 被动槽位 |
| fixed | true | 固定技能（不可更换） |
| releaseType | "instant" | 瞬发技能 |
| targetPolicy | "random_player" | 随机选择玩家目标 |
| cooldownSec | 0 | 无冷却（由攻击间隔控制） |
| allowedProfessions | [] | 空数组（怪物不使用职业系统） |
| damage.coefAtk | 1.0 | 使用怪物的 DamagePerHit 作为基础伤害 |
| damage.flat | 0 | 无额外固定伤害 |
| damage.isAoe | false | 单体攻击 |

**设计说明：**
- **单一技能定义**：所有怪物共享，减少配置冗余
- **damage.coefAtk = 1.0**：直接使用怪物配置的 DamagePerHit（不同怪物有不同伤害值）
- **targetPolicy = "random_player"**：与当前怪物攻击逻辑保持一致
- **cooldownSec = 0**：冷却由怪物的 AttackIntervalSec 控制
- **未来扩展**：特殊怪物可以单独配置 NormalAttackSkillId 指向特殊技能

#### 任务 4.2：创建 ExecuteSkillForEnemy 方法

**新增方法：**
```csharp
/// <summary>
/// 为怪物执行技能（复用 ExecuteSkill 逻辑）
/// Execute skill for enemy (reuses ExecuteSkill logic)
/// </summary>
private void ExecuteSkillForEnemy(
    string enemyId,
    Enemy enemy,
    string skillId,
    string sourceTrack)
{
    var member = _enemyTeam.GetMember(enemyId);
    if (member == null) return;

    // 选择一个默认目标用于上下文
    var defaultTargetId = SelectPlayerTarget(_config.EnemyTargetStrategy);
    var defaultTarget = defaultTargetId != null ? _playerTeam.GetMember(defaultTargetId) : null;

    // 创建战斗上下文（enemy 为施法者）
    var ctx = new BattleContext
    {
        Enemy = enemy,
        Player = defaultTarget?.Entity,
        PlayerTeam = _playerTeam,
        EnemyTeam = _enemyTeam,
        Rng = _rng,
        Clock = _clock,
        PlayerResources = defaultTargetId != null ? _playerResources.GetValueOrDefault(defaultTargetId) : null,
        PlayerBuffOwner = defaultTargetId != null ? _playerBuffOwners.GetValueOrDefault(defaultTargetId) : null,
        EnemyBuffOwners = _enemyBuffOwners,
        CurrentTargetId = defaultTargetId
    };

    // 使用 SkillResolver 执行技能
    var opts = new SkillCastOptions 
    { 
        SourceTrack = sourceTrack,
        CasterId = enemyId
    };
    var result = _skillResolver.Cast(skillId, ctx, opts);

    // 解析目标（来自技能的 targetPolicy）
    List<string> targetIds = result.TargetIds?.Count > 0 ? result.TargetIds : 
        (defaultTargetId != null ? new List<string> { defaultTargetId } : new List<string>());

    // 应用效果到所有解析的目标
    if (targetIds.Count > 0)
    {
        bool isAoe = targetIds.Count > 1;
        int damagePerTarget = isAoe ? (int)(result.DamageDealt * _config.AoeDamageMultiplier) : result.DamageDealt;

        foreach (var targetId in targetIds)
        {
            var target = _playerTeam.GetMember(targetId);
            if (target == null) continue;

            // 应用伤害
            if (damagePerTarget > 0)
            {
                ApplyDamageToPlayer(enemyId, member, targetId, target, damagePerTarget,
                    skillId: skillId, bundleId: result.BundleId);
            }

            // 即时治疗每个目标
            ApplyInstantHeal(result, enemyId, targetId, isCasterPlayer: false, skillId: skillId);
        }
        
        // Buff操作和资源变化只应用一次（不是每个目标）
        string? primaryTargetId = targetIds.Count > 0 ? targetIds[0] : null;
        ProcessBuffOperations(result, enemyId, primaryTargetId, isCasterPlayer: false);
        ApplyResourceChanges(result, enemyId, isCasterPlayer: false, skillId: skillId);
    }
}
```

**设计说明：**
- **完全复用 ExecuteSkill 的结构**：保持代码一致性
- **BattleContext 的 Enemy 字段作为施法者**：SkillResolver 会正确识别
- **支持目标选择策略**：通过 result.TargetIds 获取（来自 targetPolicy）
- **支持 AoE 伤害**：如果目标数量 > 1，应用 AoE 伤害倍数
- **支持 Buff 和治疗**：调用相同的辅助方法

**验收标准：**
- ✅ ProcessEnemyAttackViaSkillResolver 调用 ExecuteSkillForEnemy
- ✅ ExecuteSkillForEnemy 正确执行技能逻辑
- ✅ 怪物伤害正确应用到玩家
