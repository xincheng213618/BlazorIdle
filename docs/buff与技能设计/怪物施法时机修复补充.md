## 问题发现 / Problem Discovery

在修复玩家施法时机问题后，用户要求确认怪物施法系统是否也已完善。经过检查，发现**怪物也存在相同的施法延迟问题**。

---

## 问题分析 / Problem Analysis

### 玩家系统（已修复）/ Player System (Fixed)

**修复前的问题：**
```
[6.00s] 普通攻击完成
↓
等待 AttackTrack 触发（~3-5秒）
↓
[11.10s] 才检查施法
```

**修复方案：**
在 `ProcessAttackDecisionPoint` 的 PostAttack 窗口后添加 `TryStartCasting`

### 怪物系统（本次修复）/ Monster System (This Fix)

**修复前的问题：**
怪物在以下情况后不会立即尝试施法：
1. 使用瞬发技能（instant skills）后
2. 普通攻击（normal attack）后

**触发时机：**
- ✅ 战斗开始（T=0）：`ResetBattle` → `TryStartMonsterCasting` ✅
- ✅ 施法完成后：`HandleMonsterCastComplete` → `TryStartMonsterCasting` ✅
- ❌ 使用瞬发技能后：**缺失** `TryStartMonsterCasting` ❌
- ❌ 普通攻击后：**缺失** `TryStartMonsterCasting` ❌

---

## 修复方案 / Solution

### 代码修改位置 / Code Changes

**文件：** `BlazorIdle.Shared/Game/MultiBattleInstance.cs`  
**方法：** `ProcessMonsterSkillAttack`

#### 修改 1：使用瞬发技能后 / After Instant Skills

**位置：** Line 1158-1171

```csharp
if (instantSkills.Count > 0)
{
    // Execute all instant skills
    foreach (var skill in instantSkills)
    {
        ExecuteSkill(enemyId, skill.Id, "enemy_skill", isCasterPlayer: false);
    }
    
    // FIX: 怪物使用瞬发技能后也尝试施法（与玩家行为保持一致）
    // FIX: After monster instant skills, also try to start casting (consistent with player behavior)
    int nowMs = _clock.NowMs;
    TryStartMonsterCasting(enemyId, enemy, nowMs);
    
    return;  // Used instant skills, don't do normal attack
}
```

#### 修改 2：普通攻击后 / After Normal Attack

**位置：** Line 1174-1183

```csharp
// Fallback: Use normal attack if no cast/instant skills were selected
string normalAttackId = enemy.GetNormalAttackSkillId();
ExecuteSkill(enemyId, normalAttackId, "enemy_attack", isCasterPlayer: false);

// FIX: 怪物普攻完成后立即尝试施法（与玩家行为保持一致）
// FIX: After monster normal attack, immediately try to start casting (consistent with player behavior)
// 这样可以避免等待下一次 AttackTrack 触发才检查施法
// This avoids waiting for the next AttackTrack trigger to check for casting
int nowMs2 = _clock.NowMs;
TryStartMonsterCasting(enemyId, enemy, nowMs2);
```
