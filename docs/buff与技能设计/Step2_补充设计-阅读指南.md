**特色：**
- 左侧4个槽位（3主动+1被动）
- 右侧可装备技能列表
- 实时显示技能详情、消耗、冷却
- 已装备技能高亮显示

#### 3. 各职业的固定技能有什么特色？
👉 请阅读 **中篇** 第四部分：

**战士 - 架势系统：**
- 脉冲获得架势层数（最多3层）
- 满3层自动获得必定暴击buff
- 体现战士"蓄力爆发"的战斗节奏

**法师 - 奥术充能系统：**
- 法力上限确实是10点（已验证配置正确）
- 脉冲获得奥术充能（最多5层）
- 每层提升8%普攻、12%特殊伤害

**游侠 - 集中射击系统：**
- 脉冲进入集中状态（最多3层）
- 每层提升5%暴击率、3%急速

**盗贼 - 连击系统：**
- 普攻40%概率获得连击点
- 脉冲必得连击点
- 连击点用于释放终结技

#### 4. 有哪些具体的技能？
👉 请阅读 **下篇** 第五部分（5.1-5.4）：

**包含完整的1-10级技能库：**
- 战士：12个技能（猛击、致死打击、撕裂、雷霆一击、战吼、顺劈斩、破釜沉舟等）
- 法师：10个技能（寒冰箭、奥术飞弹、炎爆术、暴风雪、奥术冲击等）
- 盗贼：10个技能（背刺、剔骨、毒刃、刀扇、消失、暗影之舞等）
- 游侠：10个技能（奥术射击、多重射击、瞄准射击、猎豹守护等）

**每个技能包含：**
- 完整的JSON配置
- 详细的描述和数值
- 解锁等级
- 资源消耗和冷却
- 伤害系数或buff效果

#### 5. 实施计划有什么变化？

#### 6. JSON文件放在哪里？
👉 请阅读 **下篇** 第七部分：

**统一放在：** `BlazorIdle.Shared/Config/`
```
BlazorIdle.Shared/Config/
├── buffs.json           # Buff配置（已存在，需扩展20+个新buff）
├── skills.json          # 技能配置（新增，42个技能）
└── professionAttributes.json  # 职业属性（已存在）
```

**原因：**
- ✅ 与现有 buffs.json 保持一致
- ✅ 便于服务端战斗迁移时共享配置
- ✅ 客户端和服务端都可以访问
